# 只读大文件与日志跟随现状

更新：2026-10-16。按当前源码记录 32 MiB 及以上普通文件的窗口化只读视图与“跟随文件末尾”。来源：[`WindowedReadOnlyProvider.cpp`](../src/editor/WindowedReadOnlyProvider.cpp)、[`ReadOnlyTailController.cpp`](../src/editor/ReadOnlyTailController.cpp)、[`DocumentTailActions.cpp`](../src/window/DocumentTailActions.cpp)、[`EditorTabLargeDocument.cpp`](../src/editor/EditorTabLargeDocument.cpp)、[`CommandRegistry.cpp`](../src/app/CommandRegistry.cpp)、[`FileTierPolicy.cpp`](../src/domain/FileTierPolicy.cpp)。

## 1. 什么时候进入只读

- 普通文件磁盘大小 **≥ 32 MiB** 即用窗口化只读视图打开，生命周期内一直只读（不会后台装载成可编辑）。2 GiB 以上没有另一档。
- 加密文档不会进入此视图：加密正文必须小于 32 MiB。
- 小于 32 MiB 的二进制可编辑，不走此视图（见十六进制现状）。

## 2. 视图

- 文本呈现：每次只解码约 1 MiB 的窗口，起点对齐到行首（向前最多回看 1 MiB 找换行），终点延伸到行尾（最多补到 1 MiB）。超过 1 MiB 的单行会在窗口边界被切开显示。UTF-16 按 2 字节对齐。
- 十六进制呈现：每次约 256 KiB 窗口，与十六进制现状相同的三栏布局。二进制只用十六进制呈现；文本大文件默认文本呈现，可在标签右键“以十六进制查看 / 以文本查看”切换，保持当前位置并关闭跟随，会话恢复时按上次的方式打开。
- 一条自己的全局纵向滚动条代表整个文件位置；滚轮、PgUp/PgDn、拖动都换算到全局位置，跨窗口时即时换窗。
- 文本呈现的行号栏显示全局行号，由后台行索引提供。
- **不可用**：编辑、普通保存/另存、替换、自动换行（菜单禁用）、语法高亮、折叠、行操作、括号跳转。
- **可用**：浏览、选择、复制、查找（含正则和字节）、查找全部、结果跳转、文本大文件的查看方式切换、以其他编码显示、转换编码另存为新文件（仅文本）、跟随文件末尾。

## 3. 选择与复制

- 选区以源文件字节为准，可以跨窗口（Shift+PgUp/PgDn 扩展，Ctrl+A 选中整个文件）。
- 复制上限 64 MiB，超出提示并不复制。
- 文本呈现复制为按显示编码解码后的文本；十六进制网格复制为 `DE AD BE EF` 文本；字符栏复制同时带原始字节。
- 所有修改键、剪切、粘贴、Delete/Backspace、Insert 都被拦截不生效。

## 4. 源文件变化

- 不长期占用文件句柄，别的程序可以原子替换或日志轮转改名。
- 通过目录变化通知和每 500 ms 的元数据轮询发现变化（Windows 对原地追加不发通知）。发现变化后：立即作废进行中的查找和行号统计，搜索结果面板该文件结果失效；200 ms 防抖后重新映射文件并刷新视图。
- 读取失败、变成加密文件、读取规则缺失时显示对应提示，例如“源文件已在磁盘上变化，旧结果已失效；请等待只读视图刷新后重新查找。”
- 转换编码另存时若源文件已变化，要求重新打开后再转换。

## 5. 跟随文件末尾

- 入口：视图 › 跟随文件末尾（勾选项）、视图 › 回到末尾；只读文本和只读十六进制都可用。**默认关闭**。
- 视图顶部有一条状态行，文案随状态变化：“文件跟随已关闭”“正在跟随文件末尾”“已暂停跟随，你可以继续查看上方内容”“已停止跟随：原因”；持续变化时追加“；文件持续变化，行号和字符统计未更新”。暂停时出现“回到末尾”按钮。
- 开启时若当前就在末尾则进入跟随，否则进入暂停；开启期间暂停行号和字符统计。
- **自动暂停**：向上滚轮、左键点击、方向键、Home/End、PgUp/PgDn、Ctrl+A、产生选区、拖动滚动条离开底部、跳转到搜索结果。复制不会暂停。
- **回到末尾**：清除选区，重新映射后跳到最后并继续跟随。
- **自动停止**（需手动重新开启）：文件被删除、无法读取、被替换（身份变化）、被截断、大小不变但修改时间变化（重写）、原末尾 64 KiB 内容被改写、变成加密文件。
- 只要开着跟随，追加的内容会被接纳；处于暂停时阅读位置保持不动，不会被拉回末尾。

## 6. 状态栏

文本呈现显示“第 N 行，共 M 行”、文件大小、编码与换行、字符数（按需统计，文件变化时作废重算）。

## 7. 已知限制

- 文档里提到的“视图有界不代表搜索映射有界”：只读搜索准备阶段仍有整文件映射路径，超大文件的地址空间与资源压力需要单独验证。
- 没有“转到行 / 转到偏移”命令，只能滚动或经搜索结果跳转。
- 超过 1 MiB 的单行在窗口边界被切开显示。

## 8. 新界面原型与现状的差异

| # | 差异 | 现状 | 处理 |
|---:|---|---|---|
| 1 | 原型的只读提示条 | 现状没有只读提示条，只有跟随状态行 | 新界面可合并为一条：只读原因 + 跟随开关 + 回到末尾 |
| 2 | 原型在只读日志上显示可用的替换行 | 只读下替换全部禁用 | 必须改为禁用并说明 |
| 3 | 跟随入口 | 原型未画 | 待设计：放在提示条上，状态行文案沿用现状 |
| 4 | 状态栏“第 1,204,551 行，共 3,912,006 行” | 与现状一致 | 共计行数在统计完成前需显示“统计中” |
| 5 | 转到行/偏移 | 没有 | 如需要属于新功能 |
