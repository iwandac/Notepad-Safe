# 新界面功能核对

更新：2026-10-16。新界面设计见 [Notepad Safe 界面设计画布](https://claude.ai/artifact/7HvSVHq5npFLxc2xNhdjgU)（私有，需分享后他人才能打开）：主窗口、设计令牌与组件、失败与恢复状态、设置页、账号编辑表单、状态栏弹出层六张画板。本页把**当前源码已有的每一项用户功能**对应到新界面里的位置，确认改版不丢功能。功能来源：`src/window/MainWindow*.cpp` 的菜单与动作、`src/search/`、`src/vault/VaultDock*.cpp`、`FileCredentialDialog`、`SaveAsDialog`。

状态说明：**已画** = 画布里已有可见设计；**有位置** = 放在哪里已经确定，沿用通用组件即可，不需要单独设计；**待设计** = 需要新画面。

## 功能放在哪里

新界面不再常驻菜单栏和工具栏。现有功能分成五个入口，每项功能至少有一个入口，常用功能有两个：

| 入口 | 放什么 | 依据 |
|---|---|---|
| 左上角 ≡ 主菜单 | 保留完整的经典分级菜单：文件、编辑、搜索、视图、编码、语言、工具、帮助。按 Alt 也能打开 | Notepad++ 用户靠菜单找功能，收起来但不删掉 |
| Ctrl+K 命令面板 | 全部命令、已打开文档、最近文件、账号，都能按名字搜到 | 不记得菜单位置时的统一入口 |
| 状态栏可点击项 | 编码、换行符、语言、插入/覆盖、缩放、安全状态 | 和 VS Code 一样，看到就能改 |
| 编辑区与标签右键 | 剪切、复制、粘贴、行操作、大小写、书签；标签的关闭、复制路径、在资源管理器中显示、以文本/十六进制重新打开 | 就地操作 |
| 设置页 | 持久的偏好：主题、字号、换行、行号、空白符、标尺、Tab 宽度、自动补全、面板显示 | 取代“视图/外观”里的一次性开关集合 |

正则的实际语义（原型里用浏览器正则模拟，仅示意）：

- 引擎只有 PCRE2。小文件、加密文本和 UTF-8 大文件用 UTF + Unicode 属性模式，支持 Unicode 属性、完整字符类、前后断言和反向引用。
- 非 UTF 编码的只读大文件（UTF-16、GBK、GB18030、Big5、Shift-JIS、Windows-1252）不整文件转码，只支持日志常用子集：`.`、`^`、`$`、`|`、量词、捕获与命名捕获、反向引用、前瞻、定长 ASCII 后顾、`\d \s \w \b \R`（ASCII 语义）、开头的 `(?i)(?m)(?s)`。`\p{…}`、非 ASCII 范围如 `[一-龥]`、变长后顾、递归等在开始扫描前就提示不支持。浮层的无效提示要能显示这类原因。
- 整词：西文按单词边界；中文、日文、韩文按完整短语匹配。
- 普通查找、正则、十六进制字节是三种互斥模式。字节模式只在十六进制视图可用。

## 原型修正记录（2026-10-16 已改）

1. **锁定模型。** 改为按现有实现：登录后建立 7 天本机会话。标题栏胶囊平时只显示“已解锁”，悬停显示“本设备会话有效至 …”；剩余不到一天才出现倒计时环。状态栏写会话有效期。是否增加“闲置 N 分钟自动锁定”是新功能，另行决定。
2. **解锁画面文案。** 改为“输入主密码以开始新的 7 天本机会话”，并加了“改用文件密码或恢复密钥”。
3. **剪贴板时长。** 账号的用户名、密码、验证码提示写 30 秒；加密文档复制为 60 秒，写在设置页“安全 › 剪贴板”。
4. **快捷键。** 删除了现有程序没有的 Ctrl+L 锁定、Alt+Z 换行、Ctrl+Shift+N/A/F 等。唯一新增的是 Ctrl+K 打开命令面板（现有程序未占用）。其余沿用现有快捷键：Ctrl+R 替换、F3/Shift+F3 查找下一个/上一个、Ctrl+F2/F2/Shift+F2 书签、Ctrl+Shift+D/L 复制/删除行、Alt+↑/↓ 移动行、Ctrl+Shift+H 切换文本/十六进制、Ctrl+] 匹配括号、Ctrl+W 关闭标签。

### 第二轮：按现状文档修正（2026-10-16）

5. **加密文档扩展名**改为 `.nsafe`；默认账户文件名改为 `accounts.kdbx`。
6. **外部修改对话框**删掉“覆盖磁盘版本”，按现状为“取消（默认）/ 另存为… / 重新加载磁盘版本”，文案沿用现状。
7. **加密写回状态**：加密文档状态栏显示“已自动写回 时间 / 有修改，5 秒后自动写回 / 正在写回…”；原型里点击加密文档正文可演示这一过程。锁定后不显示。
8. **只读替换**：只读日志上展开替换时显示“只读文件不能替换；查找、复制和跳转仍可用。”，不再出现可用的替换行。
9. **查找模式**改为“普通 / 正则 / 字节”三段互斥，字节在没有十六进制视图时禁用；整词在正则下禁用；补了“循环”（默认开）；范围显示“全部打开文件 (N)”；全部打开范围下单次替换禁用；普通模式说明替换文本按字面写入；无结果时显示“未找到匹配。/已到范围边界。”。
10. **锁定时清除查找**：锁定后关闭查找浮层和结果面板，清空查询。
11. **十六进制 INS**：状态栏弹出层画板去掉普通文本上的 INS，INS/OVR 只属于可编辑十六进制。
12. **账号列表**去掉“常用”，改为现状的分组树 + 回收站节点（默认折叠），加了排序（标题/用户名/分组）和“健康检查”入口；到期账号以红色“已到期”标出；搜索提示覆盖标题、用户名、网址、标签、备注。
13. **账号编辑表单**：到期改为日期时间；生成器长度 8–128、默认 24；验证码算法写法改为 SHA1；自定义字段注明现状是多行 `name=value` 文本。
14. **设置页**：字体、字号、显示行号标为“新增”，并写明现状。
15. **状态画板**：启动恢复横幅、保存失败提示条、关闭时合并列表都标为新设计，并按现状规则修正（关闭列表里不含未命名和加密文档）。
