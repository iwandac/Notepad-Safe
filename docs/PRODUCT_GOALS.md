# 产品目标与核心旅程

更新：2026-10-17。本页是项目的**第一入口**：先读这里，再按需查专项文档。内容由 8/12 至 10/02 各版目标中始终未变的部分整理而来；演变过程见 Git 历史（`git show 8b5b2d7:docs/TARGET_EXPERIENCE.md` 有最完整的原始承诺）。

## 一句话目标

**文件离线时默认安全；可信用户使用时，它就是一个轻快、行为可预测的记事本。**

## 稳定目标

以下四项是长期目标，不随版本范围调整而删改；缺一不算完成。

1. **Notepad++ 级的编辑与搜索。**
   - 编辑：多标签、编码识别与转换、行尾、语法高亮、行操作（复制/删除/移动/排序）、书签、转到行、多选/列编辑、缩放（保存）与自动换行。
   - 搜索：字面/正则/大小写/整词、向前向后循环、当前文档与全部打开文档的“查找全部”结果面板（按文件分组、带上下文、双击跳转）、捕获组替换、当前文档全部替换一次撤销。
   - 大文件：只读也能顺畅浏览、搜索和定位。
2. **方便的账号密码管理。**
   - 与文档并列的账号工作区，标准 KDBX 存储，可被 KeePass/KeePassXC 打开。
   - 日常取用要快：搜索即得、在命令面板中直接复制、一键复制用户名/密码/TOTP（剪贴板到期清除）、密码生成、按需显示。
   - 维护要稳：编辑、历史版本、回收站与恢复；锁定后不可取用。
3. **加密文档。** 正文以标准 KDBX 格式离线加密保存；解锁后用的是与普通文件同一个编辑器、同一套搜索。
4. **现代、好看、好用的界面。**
   - 视觉上达到现代前端应用的水准：统一的颜色、字体、间距与圆角体系，明暗两套主题，图标与动效克制一致。
   - 正文优先：常驻界面元素少，查找、命令、设置按需出现；常用操作都有快捷键和命令搜索。
   - 编辑、只读、加密、账号各模式共用同一套外观与交互，差异只在必要处标明。
   - 视觉与交互参考 [界面设计画布](https://claude.ai/artifact/7HvSVHq5npFLxc2xNhdjgU)；原型只是参考，不是验收。功能做与不做以 [功能取舍](FEATURE_DECISIONS.md) 为准。

## 不变的边界

| 边界 | 规则 |
|---|---|
| 密码学 | 不自研算法或文件格式；KDBX 读写使用 KeePassXC Core + Botan，保持与 KeePass/KeePassXC 互通 |
| 离线 | 打开、编辑、保存、搜索、恢复、加解密都不访问网络 |
| 安全范围 | 保护对象是离线文件、锁定状态和应用自身留下的明文痕迹（临时文件、恢复稿、剪贴板、日志）。解锁运行中的数据不防已控制当前用户或管理员的恶意软件/间谍软件；任何界面方案都做不到，不作为选型理由 |
| 界面技术 | 原生 Qt Widgets + QScintilla（2026-10-16 决定）。理由是启动与运行要轻快；不引入 WebView、Electron 或 Qt Quick 承载主界面。现代外观靠统一设计令牌、自绘组件和主题实现 |
| 秘密隔离 | 账号密码、TOTP seed、恢复材料和密钥不进入普通文档、搜索、会话草稿、日志或明文临时文件 |
| 锁定 | 锁定后正文、搜索结果、剪贴板中的秘密与账号详情都不可取用；锁定不能只是遮罩 |
| 保存语义 | 保存保持当前类型；普通 ↔ 加密的转换只经“另存为”；任何失败都不破坏原文件，也不误报成功 |
| 文件大小 | 普通文件 < 32 MiB 可编辑；≥ 32 MiB 统一只读（浏览、搜索、定位、复制、转码另存）。加密正文严格 < 32 MiB |
| 交付形态 | Windows 单个静态 exe；本版不做安装、签名、打包分发 |
| 不做 | IDE 功能、云同步、浏览器自动填充、移动端、第三方插件市场 |
| 本版暂缓 | AI、代码可视化、Hex 新扩展（以后作为独立模块加入，不改动核心） |
| 视图规则 | 内容决定视图：文本文件用文本视图，二进制用十六进制视图，≥ 32 MiB 用只读视图；不在同一标签内切换表示，也不分屏 |

## 核心旅程

以下 12 条在**同一个当前 `notepad-safe.exe`**（KDBX=ON、隔离 `NOTEPADSAFE_DATADIR`、合成数据）中用真实键鼠走通才算通过。判据以磁盘字节、重启后状态和屏幕实际内容为准，不以函数返回值或按钮可点为准。任一条失败即是阻断，修好后该条及相邻条重跑。

| # | 旅程 | 操作 | 通过判据 | 状态 |
|---:|---|---|---|---|
| J1 | 首屏与新建 | 冷启动 → 输入中文和英文 → 撤销/重做 | 首屏 P95 ≤ 500 ms（历史 693 ms，未达标）；IME 输入不丢字；撤销分组合理 | 未执行 |
| J2 | 打开编辑保存 | 打开 UTF-8 / GBK / UTF-16 各一份 → 编辑 → Ctrl+S → 关闭 → 重开 | 编码、BOM、行尾与原件一致；只改动处变化；脏标记正确 | 未执行 |
| J3 | 日常行操作 | 复制/删除/移动行、排序（含 CRLF、末行无换行）、书签、转到行（Ctrl+G） | 未选中内容不变；行尾不被改写；一次撤销还原一次命令 | 未执行（排序已知有缺陷） |
| J4 | 查找替换 | 字面/正则/大小写/整词查找 → 当前文档与全部打开文档的查找全部 → 结果跳转 → 当前文档单个与全部替换 → 撤销 | 命中集合与独立预期一致；全部替换一次撤销还原 | 未执行 |
| J5 | 外部修改冲突 | 编辑中用其他程序改写同一文件 → 保存 | 提示冲突，不静默覆盖他人内容；可选择重载或另存 | 未执行 |
| J6 | 崩溃恢复 | 多个标签留有未保存修改（普通 + 加密）→ 强杀进程 → 重启 | 全部未保存内容与标签顺序恢复；加密稿恢复前需解锁，磁盘上无明文 | 未执行 |
| J7 | 保存失败重试 | 目标只读或被占用时保存 → 解除 → 重试；关闭窗口时选择保存/放弃/取消 | 失败如实提示、修改保留、原件不变；解除后重试成功；取消不丢内容 | 未执行 |
| J8 | 大文件只读 | 打开 ≥ 32 MiB 日志 → 头/中/尾跳转 → 正则搜索 → 跳到结果 → 复制 → 取消一次长搜索 | 不卡死；结果定位到原文对应位置；编辑入口一致拒绝；源文件哈希不变 | 未执行 |
| J9 | 加密文档往返 | 新建（默认加密）→ 设置口令 → 编辑保存 → 重启 → 错误口令 → 正确口令 | 文件是可被 KeePassXC 打开的 KDBX；错误口令不泄露内容；正确口令内容逐字一致 | 未执行 |
| J10 | 普通 ↔ 加密转换 | 普通文件“另存为”加密；加密文档“另存为”普通文件 | 仅另存为发生转换，普通保存保持类型；转换失败不留明文残留 | 未执行 |
| J11 | 账号存取 | 建库 → 新建账号 → 生成密码 → 搜索 → 显示/复制密码与 TOTP → 编辑 → 删除与恢复 → 重启 | 重开后内容一致；剪贴板到期清除；列表不显示秘密 | 未执行 |
| J12 | 锁定 | 打开加密文档与账号页时分别触发主动锁定、超时、系统锁屏 → 解锁 | 锁定后正文、搜索结果、账号详情和已复制秘密都不可取用；解锁后回到原工作状态 | 未执行 |

状态只填“通过 / 失败 / 未执行 / 受阻”，并注明 exe 的 SHA-256 与日期。代码变动后，受影响旅程的旧结果失效。

## 完成标准

- 12 条旅程在同一 exe 上全部通过，或失败项由用户明确接受为已知限制并写在本页。
- 已知缺陷清零或降级为用户认可的限制。
- 当前工作树已提交，exe 可由提交重新构建。
