# 编辑与行操作现状

更新：2026-10-17。按当前源码记录普通文本编辑区（QScintilla）的实际行为。只读大文件、十六进制、编码分别见对应现状文档。来源：[`EditorTabCommands.cpp`](../src/editor/EditorTabCommands.cpp)、[`EditorTab.cpp`](../src/editor/EditorTab.cpp)、[`EditorSurfaceStyle.h`](../src/editor/EditorSurfaceStyle.h)、[`MainWindow.cpp`](../src/window/MainWindow.cpp) 菜单构建、[`MainWindowCommands.cpp`](../src/window/MainWindowCommands.cpp)、[`CommandRegistry.cpp`](../src/app/CommandRegistry.cpp)、[`MainWindowSession.cpp`](../src/window/MainWindowSession.cpp) 设置保存。

## 1. 编辑区基础

| 项 | 现状 |
|---|---|
| 字体 | 固定 Consolas 10 pt，行号栏同字体。**没有字体或字号设置**，只能缩放 |
| 行号 | 普通文本始终显示（行号栏宽按 5 位数），**没有开关** |
| 书签栏 | 第 1 栏 16 px，橙色圆点 |
| 缩进 | 自动缩进；默认空格缩进、Tab 宽 4；显示缩进参考线 |
| 当前行 | 高亮当前行，光标宽 2 px |
| 括号匹配 | 宽松匹配高亮 |
| 横向滚动 | 只有某行真的超出视口才出现横向滚动条 |
| 自动换行 | 按词换行，折行处显示标记，续行与首行同缩进 |
| 折叠 | 方框树形折叠标记；只在有语法高亮（非纯文本）时可用 |
| 多选 | 开启 Scintilla 原生多选：输入和粘贴作用于每个选区，粘贴按选区逐个分配 |
| 新文档换行符 | 默认 CRLF；打开已有文件时改为检测到的主要换行符 |
| 插入/改写 | 文本区按 Insert 由 QScintilla 原生切换改写模式，状态栏不显示（状态栏的 INS/OVR 只用于十六进制） |
| 拖放 | 拖入本地文件一律交给主窗口作为“打开文件”，编辑区本身不接收文件拖放 |

## 2. 编辑菜单命令

| 命令 | 快捷键 | 可用条件 | 行为 |
|---|---|---|---|
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y | 可修改且有可撤销项 | QScintilla 原生撤销栈 |
| 剪切 | Ctrl+X | 可修改且有选区 | 加密文档复制后登记剪贴板指纹（见下） |
| 复制 | Ctrl+C | 有选区且文档允许复制 | 同上 |
| 粘贴 | Ctrl+V | 可修改且剪贴板有文本 | |
| 全选 | Ctrl+A | 有文档且未锁定 | |
| 复制当前行 | Ctrl+Shift+D | 普通可编辑文本 | Scintilla `LINEDUPLICATE` |
| 删除当前行 | Ctrl+Shift+L | 同上 | `LINEDELETE` |
| 上移 / 下移当前行 | Alt+↑ / Alt+↓ | 同上 | 移动选中的所有行 |
| 选择下一个相同内容 | Ctrl+D | 同上 | 无选区时先选中光标所在词；**始终区分大小写**；在全文中追加下一处为新选区 |
| 选择所有相同内容 | Ctrl+Shift+Alt+D | 同上 | 同上，一次选中全部 |
| 选区转大写 / 小写 | 无 | 同上且有选区 | |
| 合并选中行 | 无 | 同上且有选区 | 合并为一个撤销步骤 |
| 行升序 / 降序排序 | 无 | 普通可编辑文本 | 见第 4 节缺陷 |
| 十六进制插入模式 | 无（Insert 键） | 只在可编辑十六进制视图 | 见十六进制现状 |

“普通可编辑文本”指：可修改、不是只读大文件或其投影、不是二进制、未锁定。只读大文件、十六进制、锁定文档下，这些行命令全部禁用。

编辑区右键菜单由主窗口统一替换为：撤销、重做、剪切、复制、粘贴、全选（不含行操作和大小写）。编辑区内的 Ctrl+C / Ctrl+X 也被主窗口截获，走同一条复制路径，保证加密文档的剪贴板指纹都能登记。

**加密文档剪贴板**：从加密文档复制或剪切时登记剪贴板内容的指纹，60 秒后若剪贴板仍是这份内容就清除；锁定时也按指纹条件清除。不会清除用户之后复制的其他内容。

## 3. 搜索菜单中的编辑相关命令

| 命令 | 快捷键 | 可用条件 |
|---|---|---|
| 跳转到匹配括号 | Ctrl+] | 普通文本表面（非只读大文件、非二进制、未锁定） |
| 选择到匹配括号 | Ctrl+Shift+] | 同上 |
| 书签：切换 / 下一个 / 上一个 / 清除全部 | Ctrl+F2 / F2 / Shift+F2 / 无 | 有文档即可点（见第 4 节） |

书签：下一个/上一个到达末尾后回绕；光标移到书签行首并滚入视野。**书签不保存**，关闭或重启后丢失。没有“转到行”命令。

## 4. 已知问题（源码可确认）

1. **排序破坏行尾**：`text(line)` 返回的行自带换行符，代码再用 `\n` 拼接并额外追加 `\n`，结果每行之间多一个空行，CRLF 文件变成混合换行；选区结束在下一行行首时会把那一行也算进去。删除与插入是两次操作，需要按两次撤销。
2. **书签命令的可用范围过宽**：只读大文件、十六进制视图下菜单仍可点，但作用对象是内部的主编辑器，结果未核实。
3. **缩放不保存**，且只作用于当前标签。

|---|---|---|---|

| 自动换行 | 视图 | 全局，切换标签时同步到当前标签；只读大文件禁用 | 保存 |
| 显示空格与制表符、显示行尾符 | 视图 › 显示符号 | 全局，作用于所有标签 | 保存 |

| 长行标尺：显示，及 80/100/120 列 | 视图 › 长行标尺 | 全局，默认 80 列；旧设置中的其他列数就近落到三档之一 | 保存 |
| 缩放：放大 / 缩小 / 重置 | 视图 › 缩放；Ctrl++ / Ctrl+- / Ctrl+0 | 当前标签 | 不保存 |

自动补全来源为全文词语，输入 3 个字符后弹出。

没有分屏和主工具栏。旧会话中的分屏字段在恢复时忽略，下次保存不再写入；旧设置中的工具栏显示状态同样忽略并在保存时删除。

## 6. 语言（语法高亮）

23 项：纯文本、C/C++、Python、JSON、HTML、XML、SQL、YAML、Markdown、JavaScript、Java、C#、CSS、Shell、Batch、CMake、Makefile、Lua、Ruby、Perl、Diff/Patch、Properties/INI、Assembly。打开时按扩展名自动选择（例如 `h/hpp/c/cc`→C/C++，`svg/ui/pro`→XML，`ini/cfg/conf`→Properties，文件名 `CMakeLists.txt`、`Makefile`、`Rakefile` 也识别），无法识别为纯文本。手动选择只改当前标签；语言随会话恢复保存。只在普通文本表面可用。

## 7. 状态栏（普通文本）

显示：位置“行: N, 列: N”、文档总字符数、编码与换行符、文档大小、修改状态、文档类型。账号页激活时只显示账号是否有未保存修改。

## 8. 新界面原型与现状的差异

| # | 差异 | 现状 | 处理 |
|---:|---|---|---|
| 1 | 设置页的字体、字号 | 没有，固定 Consolas 10 | 新功能，需决定 |
| 2 | 设置页的“显示行号”开关 | 没有，始终显示 | 新功能，需决定 |
| 3 | 编辑区字体 | 原型用 Cascadia Mono 14 | 与现状不同，属于外观改动 |
| 4 | 右键菜单 | 现状只有撤销到全选 | 原型规划了行操作、大小写、书签，属于扩充 |
| 5 | 书签持久化、转到行 | 都没有 | 原型未画；如需要属于新功能 |
| 6 | 缩放保存 | 没有 | 实现新界面时建议一并修正 |
| 7 | 行操作的快捷键 | Ctrl+D 已被“选择下一个相同内容”占用 | 新界面不能再把 Ctrl+D 分给复制行 |

## 已确认的变更（尚未实现）

2026-10-17 按 [功能取舍](FEATURE_DECISIONS.md) 确认。分屏、转置当前行、按窗口宽度拆分选中行、主工具栏的删除与标尺三档已实现并写入正文；以下尚未实现。

- 新增转到行（Ctrl+G，仅可编辑文本）；缩放改为保存并作用于所有编辑区。
- 不做：字体选择、行号开关、书签持久化。
