# 个人日用版收尾计划

更新：2026-10-02。此前“性能后立即进入 AI”的顺序不再执行；本版只有一个收尾目标，不延续九轮功能扩展路线。

2026-10-16 起验收入口改为 [产品目标与核心旅程](PRODUCT_GOALS.md)：先跑通其中 12 条核心旅程；本页的批次和 128 个主用例只在旅程失败、需要细化时作为参考。以下为原计划。所有缺陷修复（包括单副本保留）都进入同一回归批次；[详细清单](REGRESSION_CHECKLIST.md)定义步骤与判据，[执行账本](DAILY_USE_CLOSEOUT.md)唯一记录构建身份、实际结果和未测项。当前已编制128个主用例、45组功能映射和17组外观/输入组合，参数子例尚未全部展开和执行。最新只完成副本相关5组底层CTest，尚无主用例获得“全部适用子例关闭”的结论。

## 范围

稳定完成像记事本一样轻快的普通/安全文档编辑、保存、恢复，保证离线加密安全，大文件只读与编辑内核共有阅读功能/外观一致，并保留现有账号保险箱能力。源码现状见 [FEATURE_LEDGER.md](FEATURE_LEDGER.md)，验收原则见 [TARGET_EXPERIENCE.md](TARGET_EXPERIENCE.md)，执行步骤见 [REGRESSION_CHECKLIST.md](REGRESSION_CHECKLIST.md)。

冻结新功能、AI、代码可视化和 Hex 扩展，不进行泛化重构；安装、签名、公开发布和分发不属于本版。2 GiB 不作为功能档位；32 MiB 附近验证编辑降级，超大文件另作偏移/资源压力样本。

共同阅读设置失效、行为/外观不一致属于本次修复范围，不能以“冻结新功能”推迟。wrap、全局光标行列及增强阅读能力的现有差距分别登记，不把只读禁止写入扩大解释为所有阅读功能都可缺失；本轮不自动恢复大文件编辑或扩大安全载荷。

## 统一回归批次

下面按主用例归属覆盖全部128项，不把“修一个Bug、构建一次、跑几组测试”当成独立交付。先完成批次0的执行准备，再优先验证丢内容、秘密越界和无法恢复的P0场景。每批内部按“展开子例 → 复现 → 修复 → 定向及相邻复测 → 真实客户端核对”闭环；需要桌面的子例暂存等待交接时，继续其他批次已确认无桌面的工作，不能将整批标为通过。

| 批次 | 主用例归属 | 核心验证与优先组合 | 当前状态 |
|---|---|---|---|
| 0. 观察方法与数据准备 | VAL-01至04（4项） | 确认正常打开路由、独立字节/位置真值、无效样本判别、源码/EXE身份、隔离数据及桌面交接；每批测前冻结具体子例 | 部分身份/入口已核对；子例、观察器负例与桌面准备未全部完成 |

批次1与4的安全持久化组合共用执行证据，但分别核对各自判据；批次2的EDIT-11与批次1的保存/恢复边界一并执行。批次不是P0问题等待其他P1/P2测试结束的理由。

构建是上述闭环中的验证步骤。当前沿用现有 `build-final` 的 Release 优化配置，是为了检查实际使用配置的编译、链接和行为；目录名及配置名不表示发布、完成验收或已经冻结候选。代码变化后先构建受影响目标并运行定向/相邻回归，需要客户端验证时更新产品EXE并记录新身份；只有文档整理不重建。修复稳定后再固定统一候选汇总结果，不要求每个小修都跑整套，也不把小修通过当作整体完成。

退出条件：128个主用例展开后的适用子例有可核查结果；无未处理P0阻断，P1差距明确处理，未执行/受阻不能算通过；客户端结果与实际字节/重启状态一致，性能独立报告。发现非阻断扩展需求列后续，不扩展本版范围。

## 下一步执行顺序

1. 完成VAL中的观察器和首批子例准备，核对当前工作树与测试链接对象，明确哪些入口确实不占桌面。
2. 合并验证批次1：把已有普通保存/恢复/无效清单保全与单副本改动放在同一当前版本，先做Core容量、故障、混合文档状态和相邻回归；补充SAV-09尚未验证的删除边界与提交后状态，不只重跑已经通过的5组测试。
3. 在等待桌面交接期间推进批次2至4能独立执行的夹具和逻辑验证；取得交接后，按日常编辑→跨模式阅读/搜索→保存恢复/安全锁定的连续流程核对可见客户端，复用同一输入和数据真值。
4. 发现缺陷留在所属用例中修复与复测，更新唯一账本；功能边界闭合后固定候选，执行批次5并汇总整体验收结论。

## 桌面和数据

computer use 与 BD2 共享。GUI、剪贴板、快捷键和可能显示窗口的测试都需明确交接；idle 不等于释放。以任务消息记录占用，不在文档中永久写死占用方。

源码、用例编写及已核实入口的 Core 测试可先进行。run_tests.bat 的 non-GUI 集合含 QApplication，不能在 BD2 占用时直接运行。使用隔离 NOTEPADSAFE_DATADIR、合成凭据和自有文件。

GUI 独占与低负载测量不同；BD2 后台构建也会干扰性能。结束桌面测试后明确归还，不建立额外持续监控。
