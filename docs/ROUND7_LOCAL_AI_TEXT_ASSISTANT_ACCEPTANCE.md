# 第 7 轮：本地 AI 文本助手验收契约

> 状态：设计完成；模型来源与 Secure 跨进程策略等待产品批准
> 更新日期：2026-08-30
> 前置条件：第 5 轮工具基座关闭；优先推进真实文本助手，不等待第 6 轮所有语言完成，不依赖 Windows 安装发布

## 1. 用户结果

文档助手提供五个明确任务，而不是通用代理：

- **解释**：先给结论，再说明选定文字/代码的关键部分。
- **总结**：压缩选区，保留明确事实，不补充外部知识。
- **改写**：按用户选择的“更清楚 / 更简洁 / 更正式 / 更友好”生成建议。
- **续写**：只根据获批上下文生成后续文字，明确它是草稿。
- **按要求生成**：用户填写目的、受众和约束，生成新建议，不伪装成原文事实。

所有结果先进入内存预览；解释/总结是只读 Artifact，改写/续写/生成形成 TypedEditProposal。产品不自动保存、执行、复制、上传或加入恢复稿。

## 2. 产品决定门

实现真实 Provider 前必须批准：

1. 本地测试模型来源：用户提供的文件或其他明确获批的本地文件，以及模型/量化/模板/许可证/sha256 的权威 manifest。本次不安排模型捆绑分发或自动下载；若本机没有合规模型，单独提出所需材料与权限，不自行联网获取。
2. 本地运行方式：推荐固定版本独立 loopback 进程（如获批的 llama.cpp server），由产品管理生命周期还是连接用户已有服务。
3. 已解锁 Secure Note 是否可把明文发送到外部本地进程。默认仅 Plain 可用；进程内确定性工具不受此门影响。
4. 模型缓存、对话/结果是否持久化。默认只保存模型文件，不保存 prompt、正文、输出、embedding 或聊天历史。
5. CPU/GPU 最低要求、支持的 Windows/显卡范围与无加速时的产品降级。

缺少决定时可以完成 Provider contract、fake negative tests 和 UI disabled state，但不得声称“本地 AI 可用”。

AI-D0 集中整理这些决定，不代替产品批准。实际开发先串通 7A/7B 与“总结、改写”的 7C/7D 真实模型旅程，再补齐另外三个任务；此中间里程碑不改变本轮完整退出门。代码的确定性事实增强需等待对应语言的第 6 轮 CodeModel 通过，纯文本助手无此依赖。

## 3. 本地推理安全边界

`InferenceService` 是唯一策略入口。它接收一次性的 ApprovedDocumentSlice 和结构化 task，不接收路径、EditorTab 或任意 system prompt。模型输入把文档明确标记为不可信数据；文档中出现“忽略指令、运行命令、上传文件”等内容不能改变工具权限。

loopback 不是天然安全：

- endpoint 固定为 loopback，端口/协议/模型/template identity 必须握手验证；拒绝非 loopback、重定向、代理和未登记模型。
- 模型进程没有文件、Shell、网络工具能力；Notepad Safe 不把 function/tool calling 暴露给它。
- 不自动下载、不远程 fallback、不扫描任意模型目录、不加载动态插件；模型与 runtime 进入固定供应链/SBOM。
- 请求/响应、路径、正文、query、token 文本不进入日志；只记录 provider/model id、字节/token 计数、时长、取消与错误码。

## 4. 切片 7A：Provider 健康、模型身份与生命周期

### 验收

- 服务不存在、启动失败、端口被占、错误协议、错误模型/template hash、健康检查超时、响应中途退出和版本不兼容均 fail closed，并给出可操作下一步。
- 首帧前零 GPU 探测、服务启动、模型文件扫描和 Provider 实例；首次打开助手仍只显示轻量状态，用户明确运行时才连接/启动。
- 关闭最后请求、退出、切换模型和崩溃重启的进程/端口/cache 生命周期确定；不杀用户未由产品拥有的进程。
- 模型 manifest 缺失、许可证/sha/hash 不符和模型路径越界时拒绝加载；不能“尝试一下”。

## 5. 切片 7B：流式生成、预算、超时与取消

### 设计

流式文本只进入一个有界内存 buffer 和当前可见预览；不把每个 token 变成 QWidget/Undo 命令。UI 显示正在处理、已生成量、停止和结构化错误；首 token 前也保持可取消。

### 验收

- 输入字节、上下文 token、输出 token、总时间、单 chunk、累计内存均有硬上限；超限在发送/追加前拒绝或停止并解释。
- 30 轮记录 time-to-first-token、总耗时、token/s、RSS/private bytes、线程/句柄、UI heartbeat；不提供跨硬件宣传数字。
- Cancel 到 Provider 停止/连接关闭/内存不再增长目标 <100 ms；取消后迟到 chunk 不显示、不形成 Proposal。
- timeout、malformed JSON/SSE、invalid UTF-8、超长 chunk、重复 completion、连接复用污染和服务强杀均保持编辑器可用、原文不变。

## 6. 切片 7C：五种任务与产品语言

每种任务使用固定、版本化 task template，输出先经过结构/长度/Unicode 验证。模型不是事实来源：

- 解释必须区分“原文明确说明 / 根据文字推测 / 无法确认”；代码事实优先引用第 6 轮 CodeModel。
- 总结只能引用获批范围，不暗示检查了全文或外部资料。
- 改写 Diff 明确显示删除/新增；不得更改未选范围。
- 续写默认在选区尾或 caret 提案插入，显示“AI 草稿”。
- 按要求生成必须显示用户提供的目的、受众和约束；空约束不替用户猜测敏感事实。

golden 不是断言模型逐字输出，而是断言范围、task/template/model identity、预算、Artifact/Proposal schema、禁用动作、stale/cancel 与数据泄露。质量由一组固定人工 rubric 评估：忠实、清楚、可采用、无未声明事实、无危险动作，每项给出样本与失败理由。

## 7. 切片 7D：预览、应用、Undo 与真实模型 E2E

- Plain Text：五任务各完成选择 → 授权 → 本机位置 → 流式预览；解释/总结只读，关闭或取消后正文、dirty 与磁盘不变，不出现 Apply/Undo 修改流程。改写/续写/生成分别完成 Diff → Apply/Cancel → 一次 Undo → 保存/重开并校验实际结果。
- Secure Note：若未批准跨进程，入口明确说明“安全文档目前只支持本应用内工具”，且零请求；若批准，逐次显示范围与本地进程身份并执行同等加密恢复验证。
- Accounts、锁定、B2/B3 修改任务硬拒绝；B2/B3 只读解释若启用也必须是明确有界选区。
- 文档编辑、关闭、锁定、Provider/模型切换使旧结果立即 stale；Apply 前再次检查原 hash。
- 使用一份固定、许可证允许本地使用/测试的真实模型完成离线 E2E；本次不分发模型。fake Provider 只用于错误覆盖，不得代替真实流式、取消、资源和质量证据。
