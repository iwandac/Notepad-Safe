# 十六进制现状

更新：2026-10-16。按当前源码记录二进制文档与十六进制视图的实际行为。来源：[`EditorTabHex.cpp`](../src/editor/EditorTabHex.cpp)、[`EditorTabLargeDocument.cpp`](../src/editor/EditorTabLargeDocument.cpp)、[`ByteClipboard.h`](../src/editor/ByteClipboard.h)、[`HexProjection.cpp`](../src/editor/HexProjection.cpp)、[`PatchList.cpp`](../src/editor/PatchList.cpp)、[`FileContentProbe.cpp`](../src/editor/FileContentProbe.cpp)、[`MainWindow.cpp`](../src/window/MainWindow.cpp) 的编辑/视图菜单；契约见 [十六进制契约矩阵](../tests/gui_smoke/HEX_EDITOR_CONTRACT_MATRIX.md)。

## 1. 哪些文档有十六进制

| 文档 | 默认呈现 | 可否编辑字节 | 可否切到文本 |
|---|---|---|---|
| 小于 32 MiB 的二进制 | 十六进制 | 可以 | 可以，文本呈现只读 |
| 32 MiB 及以上的二进制 | 十六进制 | 不可以 | 可以，只读 |
| 32 MiB 及以上的文本（只读大文件） | 文本 | 不可以 | 可以切到十六进制，只读 |
| 小于 32 MiB 的文本 | 文本（QScintilla） | — | **不能切到十六进制** |
| 加密二进制 | 十六进制 | 可以（加密正文须小于 32 MiB） | 可以，文本呈现只读 |

二进制判定见 [编码现状](ENCODING_CURRENT_STATE.md)：前 64 KiB 有 `00` 字节或控制字符超过 3%。

切换：视图 › 呈现方式 › 文本 / 十六进制，或 Ctrl+Shift+H 双向切换；只在上表“可以切换”的文档可用。切换不改字节、不保存。

## 2. 布局

- 三部分：左侧地址栏、中间纯十六进制网格、右侧字符栏，共用一条纵向滚动条和同一行高。
- 地址为十六进制，位数至少 8 位，按文件大小增加。
- 每行字节数按窗口宽度自适应：在 64 到 8 之间以 4 为步长取能放下的最大值；窗口缩放时重排，不改数据、光标和选区。
- 字符栏按当前显示编码解码：多字节字符显示在其第一个字节的格子里，后续字节格留空；非法字节显示 `�`。可通过编码菜单“以 … 编码显示”切换。
- 二进制切到文本呈现后，行号栏改为十进制全局字节偏移，不建立全文行索引。

## 3. 光标与选择（十六进制网格）

- 光标定位到字节的高/低半字节，永不停在分隔空格上。
- ←/→：高 → 低 → 下一字节高，反向同理；↑/↓、PgUp/PgDn 按行移动并保持半字节；Home/End 到行首字节高位 / 行尾字节低位；Ctrl+Home/End 到文件首/尾（尾部可作为插入点）。
- Shift 或 Ctrl+Shift 加方向键扩展选区，按完整字节计算；鼠标拖选同样按完整字节。字符栏的选区与网格互相镜像。

## 4. 编辑（仅可编辑的二进制）

**改写/插入模式**：默认改写（OVR）。切换方式：Insert 键、编辑 › 十六进制插入模式、状态栏常驻的 INS/OVR 按钮。模式对整个文档共享。

**网格输入**（只接受 0–9、A–F、a–f）：

| 情况 | 结果 |
|---|---|
| 有选区 | 整个选区替换为一个字节 `X0`，再输入第二位完成该字节 |
| 插入模式，光标在高位 | 插入新字节 `X0`，第二位补全低位 |
| 改写模式或低位 | 修改当前字节对应半字节；改写模式在文件末尾不能增长 |
| 其他可见字符 | 拒绝，状态栏提示“十六进制视图只接受 0–9、A–F；ASCII 栏为同步预览。”并响铃 |

**字符栏输入**：输入的文字按当前显示编码编码成字节写入（例如 UTF-8 下一个汉字写 3 个字节）；含控制字符或该编码无法表示时整段拒绝并提示。改写模式在文件末尾不增长；有选区时替换整个选区。

**输入法**：预编辑内容不进入网格；提交时整段校验，合法就作为一次操作写入，混入非法字符则整段拒绝。

**删除**：Delete 删光标处字节，Backspace 删前一个字节；有选区时删除选区。文件开头 Backspace、文件末尾 Delete 无操作。

**剪贴板**（单次上限 64 MiB，超过提示“剪贴板内容超过 64 MiB…本次操作未应用”）：

| 操作 | 网格焦点 | 字符栏焦点 |
|---|---|---|
| 复制 / 剪切 | 文本格式 `DE AD BE EF` | 同时放入私有原始字节格式和按显示编码解码的文本 |
| 粘贴 | 把剪贴板文本按十六进制解析（空格、逗号、连字符、`0x` 均可）；解析失败提示“剪贴板中没有十六进制字节。” | 优先用私有原始字节；否则把文本按显示编码编码，无法无损表示则拒绝 |
| 改写模式粘贴 | 从光标起覆盖，超过文件末尾的部分被截掉，不增长文件 | 同左 |

编辑菜单的剪切/复制/粘贴按当前焦点所在的一侧执行。

**撤销/重做**：每个用户操作一个历史单元（两次半字节输入合为一个字节输入）。补丁超过内存上限（物理内存的 1/20 量级）溢出后，撤销/重做历史清空并提示。

## 5. 只读十六进制

只读大文件和 32 MiB 以上二进制：导航、选择、复制、搜索可用；所有修改键、剪切、粘贴、删除、Insert 键都被吞掉不生效，菜单中相应命令禁用。

## 6. 搜索

见 [搜索现状](SEARCH_CURRENT_STATE.md)：十六进制字节模式只在十六进制视图可用，只查找不替换；从字符栏复制的内容粘到查找框会自动切到字节模式；结果面板第一列显示“偏移 0x…”。

## 7. 保存与恢复

- 按字节模型原样保存，不经过文本编码；字符栏的 `�` 不会触发“编码需要确认”。
- 未修改时保存为空操作。
- 崩溃恢复保存字节补丁、修改状态与位置（细节见保存与恢复现状）。

## 8. 状态栏

显示字节位置、选区长度、文件大小、文档类型，以及可点击的 INS/OVR（仅可编辑十六进制）。

## 9. 新界面原型与现状的差异

| # | 差异 | 现状 | 处理 |
|---:|---|---|---|
| 1 | 十六进制画面 | 原型没有画 | 待设计：地址 / 网格 / 字符栏三栏、INS/OVR、只读状态 |
| 2 | 呈现方式切换入口 | 菜单与 Ctrl+Shift+H | 新界面放状态栏；小文本不能切十六进制，需显示为不可用 |
| 3 | 字符栏输入规则 | 按显示编码编码，不是 Latin-1 | 设计说明应以现状为准 |
| 4 | 状态栏 INS/OVR | 只在可编辑十六进制出现 | 原型的弹出层画板把 INS 画在普通文本上，需改 |
