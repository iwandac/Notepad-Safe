# 当前功能回归与验收方法

> 更新：2026-10-02。本文依据当前源码、CMake 测试注册和测试实现整理，定义验收方法。实际结果统一见 [执行账本](DAILY_USE_CLOSEOUT.md)：已有单副本相关5组底层测试通过，完整客户端回归尚未完成。
> 本次产品目标：像记事本一样轻便、快速、容易使用；加密文件离线安全；只读与编辑模式共有功能及外观一致。当前实现限制不自动成为验收豁免。逐项步骤见 [详细验证清单](REGRESSION_CHECKLIST.md)，源码现状见 [功能清单](FEATURE_LEDGER.md)，结构见 [当前架构](DESIGN.md)。

## 0. 本次验收目标

本轮以用户最新目标、可复现正文/字节真值和实际界面结果为依据；旧需求中的大文件分档、只测按钮可用或把功能缺失当成通过的口径不继承。当前源码可用于发现路径和限制，不能自己充当正确性的唯一标准。

| 主线 | 通过要求 | 不能替代的证据 |
|---|---|---|
| 日用轻快 | 打开、输入、选择、复制、查找、保存、关闭重开连贯；失败可理解且可重试；有实际输入呈现与资源数据 | 构建成功、窗口visible、消息泵心跳或单次快速样本 |
| 跨模式一致 | 对相同片段与相同输入，共有阅读动作的正文、选择、剪贴板、搜索范围和样式一致；设置变更作用于可见表面 | 构造时style属性相等、两个模式各自跑一条正常流程 |
| 只读边界透明 | 修改入口一致拒绝；已支持的复制/搜索/定位/转码可用；成本上限明确且不静默截断 | 把菜单禁用当成所有只读体验均正确，或把当前不支持当不适用 |
| 离线安全 | 合成凭据全流程离线、密文/恢复稿正确、锁定/到期/异常退出无秘密越界，失败与丢失风险如实反馈 | 仅正确密码解锁成功、静态无网络类、只检查遮罩 |

当前wrap、光标全局行列、语言/折叠/分屏的只读差异在详细清单中登记；本轮优先共同功能及已暴露设置的正确性，不通过恢复大文件全文编辑来追求表面一致。允许只读标识、滚动总范围、异步统计的明确pending等必要区别。安全正文上限保留，但用户必须知道可读取不等于能加密输出。

具体执行使用详细清单的128个主用例及参数子例、17组外观/输入组合。每个功能都有真实源字节或可见结果判据；没有实际结果的格子保留未执行。

## 1. 回归结论的含义

文本编辑器的测试单位是“文档模式 + 内容 + 状态 + 连续操作 + 可核对的结果”。按钮存在、函数返回成功、某个 GUI 测试通过，均不能代表整项能力通过。

- 功能清单逐项关联真实命令/控件、能力判断、测试入口与剩余缺口。
- 每条执行记录标识源码版本及工作树差异、产品/测试 EXE 哈希、KDBX 开关、Qt/Windows、fixture 哈希和隔离 profile。
- 结果分为：通过、失败、未执行、受阻、不适用。注明逻辑、Qt 集成、可见 GUI 或正式进程层次；不能互相代替。
- 历史日志只证明记录对应的候选和切片。新增或修改代码后的旧绿色结果不自动继承。
- “完整回归”指冻结清单内的适用用例都有结果，且失败和未覆盖项公开；不等于穷尽全部组合或证明没有 Bug。
- 三条日用流程是最终交叉检查，不能替代编辑、编码、Hex、搜索、恢复、安全及账号的功能边界回归。

## 2. 按当前实现区分模式

下表描述源码当前模式，不是对全部现状的验收认可。模式以实际打开路由和 capabilities 为准，不以扩展名、旧 S1/S2/S3 名称或测试函数名推断。

| 模式 | 可验证的实际操作范围 | 必查限制 |
|---|---|---|
| 普通可编辑 Text | QScintilla 正文、编辑/撤销、搜索替换、保存、分屏、语言和视图设置 | 原始大小与 UTF-8 解码展开后的大小均影响只读降级；不能只用磁盘大小判断 |
| 小型 Binary 的 Hex | `VirtualFileView`/`PatchList` 字节编辑、选择、插入/覆盖、撤销、字节搜索与保存 | Hex nibble、字节坐标和字符投影分别验证；文件尾及不完整行不可越界 |
| 小型 Binary 的 Text 解释 | 按选定编码浏览同一原始字节、定位和搜索 | 不是普通完整 Text 编辑器；按能力确认只读、byte-offset gutter 与不可用命令 |
| 普通窗口化只读 Text | 连续浏览、搜索、复制、定位、按需统计；符合条件的普通 Text 可单独转码到新路径 | 普通保存/另存、编辑/替换、自动换行等受限制；转码导出不能被误判为普通保存可用 |
| 普通窗口化只读 Binary/Hex | 有限投影、全局字节位置、Text/Hex 解释、搜索/复制 | 不编辑、不保存修改；不得隐式加载完整可编辑副本 |
| 安全草稿/已解锁安全 Text 或 Binary | 在安全大小约束内复用相应小文件编辑表面，密文持久化与恢复 | 安全 payload 严格小于 32 MiB；Text/Hex 能力仍随内容和表示变化 |
| 已锁定安全文档 | 遮蔽、解锁与保留恢复责任 | 编辑、搜索、复制及秘密读取不能绕过锁定；锁定失败分支不能只看遮罩 |
| Accounts、安全中心、无文档 | 各工作区自己的操作、空态与命令归属 | 文档菜单、快捷键、状态栏不能作用于隐藏文档或残留旧元数据 |

普通文件在 **32 MiB 处及解码展开触发条件**降级；当前不存在 2 GiB 功能分界。源码里的 `LargeReadOnly` / `HugeReadOnly` 是残留尺寸分类，两者走同一窗口化只读能力。超过 2 GiB 的样本用于 64 位偏移、资源和定位压力验证，不建立额外产品档位。

源码核对点：`src/domain/FileTierPolicy.h`、`src/editor/EditorTab.cpp`、`src/editor/EditorTabLargeDocumentPersistence.cpp`、`src/window/MainWindowCommands.cpp`、`src/domain/DocumentState.h`。

下列各行是待展开并执行的回归组，不是通过记录。每个组都要覆盖适用模式下的成功、拒绝、取消、失败后重试及第二次操作；不适用组合说明对应能力约束。

| 回归组 | 操作及组合重点 | 必须核对的结果 |
|---|---|---|
| 打开与路由 | 菜单/快捷键、拖放、命令行/第二实例、最近、恢复；同路径/物理别名；混合有效无效批次 | 文件身份、重复标签、已有 dirty 状态、内容类型、失败反馈和当前工作区 |
| 基础编辑 | 输入/IME、删除、换行、Tab/缩进、选区替换、剪切粘贴、多选；头/中/尾；空/反向选区 | 正文与字节、caret、dirty/revision；撤销重做恢复准确且分组正确 |
| 行与导航命令 | 复制/删除/移动/排序行、大小写、书签、Go To、选词/行；最后一行无换行 | 未选内容不变；行尾、选择和下一次操作正确；保存重开一致 |
| 视图与标签 | Text/Hex、分屏、wrap、zoom、lexer、主题；标签重排、关闭其他/全部；Dock 开关 | 文档身份/内容不变；共有设置与操作跨模式一致；只读 wrap 等现有缺失另列体验差距，不以拒绝正确冒充一致性通过 |
| 编码与行尾 | 自动探测、以指定编码显示、另存转换、EOL；BOM、多字节、无末尾换行、混合 EOL、非法字节、不可表示字符 | 显示解释不改源文件；转换遵守严格编码；失败不提交损坏目标；原件/新文件角色清楚 |
| 只读转码 | 只读普通 Text → 选择目标编码/新路径 → 取消/失败/成功；转换中源被替换 | 普通 Save/SaveAs 仍拒绝；新目标内容与独立解码期望一致；源变化时不提交 |
| Hex 输入与选择 | 两表面同步、nibble、插入/覆盖、IME、复制格式、粘贴、删除、Undo/Redo；空/1/15/16/17 字节 | 精确 byte range、EOF、不完整行、粘贴原子拒绝、文本投影不能静默改字节 |
| 当前文档查找 | literal/regex/byte、大小写/整词/方向/循环、空查询、无匹配、零宽/多行/捕获组 | 独立预期命中集合及顺序；源字节坐标与实际可见高亮；重复查找前进语义 |
| Find All 与结果 | 单文档/全部打开、渐进批次、容量边界/spool、双击、Dock 隐藏重开 | 不漏报成成功；取消/失败/截断明确；旧 revision、源文件变化后结果失效 |
| 替换 | 当前匹配、全部、捕获组、转义、全部打开中的可编辑/只读/锁定混合 | 只改合法目标；计数及跳过说明真实；错误时不部分误改；一次 Undo 还原所承诺的事务 |
| 大文件浏览 | 头/中/尾、投影边界、多字节/CRLF、超长单行、跨窗口选择复制、快速远距跳转 | 屏幕 marker 与源 byte range 一致；无回跳/缺口；EOF 可达；源 hash 不变 |
| 日志跟随 | 开启/暂停/恢复/关闭、手动导航、分段追加、删除/截断/替换、安全格式替换 | 用户阅读位置优先；故障停止且不自动恢复；UTF-8/CRLF 边界完整 |
| 异步任务 | Queued/Running 取消、立即重试、查询换代、目标关闭、结果跳转重入、搜索全文件映射失败、实际 I/O 失败 | 领域状态与任务终态一致；没有旧结果覆盖、新查询被误取消或访问已关闭数据源 |
| 普通保存 | 保存/另存、外部修改、候选打开/写入/提交失败、提交后版本捕获/重开 backing 失败 | 检查磁盘原件、候选、正文、dirty 和下一次保存；返回 Error 时也须区分提交前失败与已提交后的失败 |
| 会话与恢复 | 正常退出/重启、强制结束后恢复、恢复中关闭/取消、重试/移除/明确放弃 | fresh reader 可找回完整责任；标签顺序/活动项正确；不得把恢复失败当原文件成功 |
| 无效清单保全 | 损坏/不可读/未来版本、默认取消、明确保全、复制/正文/清单故障、解除后重试 | 原资料保全、索引完整、新旧正文独立可读；失败不退出；普通清理不删保全目录 |
| 安全文档 | 新建/保存/重开、Plain↔Secure 转换、历史/外来凭据、恢复材料、大小限制 | 内容与身份不串用；普通保存保持类型；失败不留下明文恢复稿或静默丢弃 |
| 安全生命周期 | 主动锁定、会话到期、系统锁定、后台化；搜索/保存/恢复期间触发 | 正文/搜索/剪贴板与凭据同时遵守策略；主动锁定可取消与到期清除路径分别验证 |
| Accounts | 空态、创建/编辑、搜索、密码生成/显示/复制、TOTP、历史、回收站/恢复/永久删除、重启 | 真实 KDBX 重开一致；列表不携带秘密；超时及工作区切换清理；取消不持久修改 |
| Shell/设置/可访问性 | 首屏、菜单/快捷键归属、布局/设置恢复、键盘-only、DPI/窄窗、错误详情 | 可发现且可操作；无裁切、焦点丢失、动态 UIA 名称过期或旧文档状态残留 |

矩阵中的“全部打开”不是目录搜索。目录搜索、AI、代码可视化、Hex 扩展与安装分发不加入本版实现范围。

## 4. 数据与组合覆盖

### 4.1 夹具边界

- 大小：0、1、典型小文件；32 MiB−1、32 MiB、32 MiB+1；磁盘小但 UTF-8 展开超界；64/256 MiB 与超过 2 GiB 的独立压力样本。大样本按本次验证目标选取，不对全部功能重复全量扫描。
- 内容：UTF-8/BOM、UTF-16 LE/BE、GBK/GB18030、Big5、Shift-JIS、Windows-1252；CRLF/LF/CR/混合、NUL、组合字符/emoji、非法/截断序列、极长行及 EOF。
- 搜索：无/单/多/密集命中，窗口和解码边界命中，超过 `int` 范围的源偏移；现有容量用例覆盖 200000 与 200001 命中，不能用总结果计数代替尾部结果导航。
- 持久化：已存在/新目标、权限或共享句柄阻止替换、同大小原子替换、truncate、候选或恢复目录被文件占用、清单无效。
- 安全：独立测试身份和合成秘密；KDBX ON 验真实后端，OFF 验拒绝/禁用与普通功能不回退。fake backend 通过不能当真实 KDBX 通过。

只使用临时 profile 和合成/批准的只读原件。现有真实大文件不得改写或删除；测试不触及用户真实账号库、密码、恢复密钥。截图、日志、fixture 路径及清理范围均归测试实例所有。

### 4.2 控制组合数量

先列出合法组合，再按风险选择覆盖，不做未经论证的完整笛卡尔积：

1. 数据/安全边界逐项明确用例：编码往返、Text/Hex 坐标、保存失败、恢复责任、锁定及秘密清理，不以随机抽样替代。
2. 普通交互维度用成对覆盖，记录选中的组合与未覆盖项；有三因素风险时明确补组合，如“非 UTF-8 + 跨投影选择 + Text/Hex 切换”。
3. 各命令验证入口与能力一致：菜单、快捷键、上下文、直接输入按实际可达入口选择；底层拒绝不能代替 UI 禁用，UI 禁用也不能代替底层拒绝。
4. 共同路径可复用夹具和步骤，但不能因界面相似省略不同数据源、持久化方式或锁定状态。

## 5. 必须包含的操作序列

以下为本版重点组合序列，均需登记执行结果；源码存在相近测试不表示这些完整序列已经执行。

| 序列 | 操作 | 独立判据 |
|---|---|---|
| R01 编辑后查找 | Find All → 编辑 → Undo → 点击旧结果 → 重查 → 替换 → 保存重开 | 旧结果失效策略、当前 revision、独立期望正文与字节 |
| R02 编码与表示 | 非 UTF-8 Binary → Text 解释 → 搜索 → Hex → 选择复制 → 改编码解释 | 原字节不变；每次选择对应同一源范围；能力不误开放 |
| R03 编辑历史 | 多选替换/行操作 → Undo/Redo → 保存 → 再编辑 → 关闭取消 → 保存重开 | 撤销分组、dirty、正文、后续动作均一致 |
| R04 只读拒绝 | 降级 Text/Hex → 键盘/菜单修改尝试 → 替换/保存尝试 → 复制/搜索 | 原件 hash、无编辑副本/恢复正文、可用动作仍工作 |
| R05 转码独立出口 | 只读 Text → 普通保存拒绝 → 转码到新路径 → 源变化失败 → 重试 | 两个文件的身份、编码/字节、失败目标与下一次操作 |
| R06 任务交错 | 排队搜索 → 取消 → 立即新查 → 关闭旧目标 → 隐藏重开 Dock | 精确 TaskId/generation 终态；新结果不被旧回调改写 |
| R07 结果与外部源 | Find All/spool → 原子替换/截断/追加 → 双击旧结果 → 重查 | 旧结果拒绝；重新准入；不能把新的安全文件当普通字节读取 |
| R08 多稿故障 | 两个以上 dirty 文档 → 前项快照成功/后项失败 → 关闭拒绝 → 解除故障重试 → 新进程恢复 | 每个稿完整可解密、原件不变、未成功发布不误记 revision；不能只核对第一项 |
| R09 清单保全 | 无效清单 → 正常关闭 → 默认/ESC 取消 → 继续编辑 → 保全 I/O 失败 → 重试保全退出 → 重启 | 真实对话框与焦点、所有原始资料/副本索引、新旧正文、关闭结果 |
| R10 恢复交错 | 首帧/首次投影/部分交付/完成时关闭 → 取消或接受 → 重启；中途重排/点选 | 未交付和在途稿责任保留；不重复恢复；用户当前项不被后到回调夺回 |
| R11 安全交叉 | 安全文档编辑/搜索 → 锁定或到期 → 保存/恢复故障 → 解锁 → 重查/保存重开 | 按触发原因核对正文处理和秘密清理；不能只以遮罩可见为准 |
| R12 工作区交叉 | 文档 dirty/分屏/搜索 → Accounts 编辑/取消/保存/复制 → 切回 → 锁定 → 重启 | 焦点和命令归属、文档状态保留、账号真实持久化、秘密超时清理 |

## 6. 结果真值与测试层次

### 6.1 独立结果真值（oracle）

- 文本/Hex：预先生成期望字节或独立转换结果，逐字节比较。不能用同一个产品编码/位置函数同时产生输入期望和验证结果。
- 搜索：夹具生成时记录匹配源 byte range；检查屏幕首尾 marker、选区和磁盘数据，不只比较内部 offset/命中数量。
- 保存：比较原件/目标 hash、类型头及重开内容；失败需要核对 dirty 和可重试状态。`commit()` 成功不代表后续重开或版本验证也成功。
- 恢复：从新 `SessionManager` 或新进程读取实际清单与密文稿，逐项核对；不得只看当前内存或旧对象的缓存。
- 安全：合成秘密用于判定锁定后不可访问、剪贴板条件清理和持久化无明文；不声称能抵抗同用户恶意进程或回收系统已保存的剪贴板历史。
- UI：实际可见控件、焦点、选择、渲染和可达动作是判据；直接 `QAction::trigger()` 只证明动作连接，不能证明键盘、菜单命中或可访问性。

### 6.2 各层可证明什么

| 层次 | 当前入口举例 | 不能上推的结论 |
|---|---|---|
| 核心/无窗口 | `test_closeout_persistence` 使用 `QTEST_GUILESS_MAIN`；编码、PCRE2、文件读取/重命名相关测试 | 不证明对话框、焦点、菜单、正式进程或屏幕渲染 |

未来运行时先用配置对应的 `ctest -N` 核对实际注册，再记录选择表达式和匹配列表。Qt 初始化/清理计数、CTest 用例数、数据行数分开报告；SKIP、超时、观察器失败不得算业务通过。

## 8. 执行与关闭顺序

1. 固定当前源码和候选身份，按 [详细清单](REGRESSION_CHECKLIST.md) 展开具体子例账目。先核对现有测试是否强制内部windowed路径、仅检查颜色方差或只计窗口visible；记录其真实证明范围。
2. 先做无桌面静态和核心测试；复现确定缺陷，按影响链补故障断言并最小修复。修复后重跑受影响组和必要邻接组。
3. 取得共享桌面明确交接后，串行运行可见 GUI 与正式 EXE 回归；绑定自有 PID/profile/窗口，焦点不属于测试实例时停止输入。完成后归还桌面。
4. 性能在单独低负载窗口测量，记录其他构建/客户端负载；独占鼠标不等于性能环境安静。保留所有样本、失败和观察器开销。
5. 汇总冻结矩阵的结果、失败复现和未执行项。正文丢失/错误覆盖、秘密越界、核心操作不能完成、崩溃/不可恢复卡死为阻断；其他限制明确呈报，既有性能门例外由用户决定。

执行记录最小字段：`CaseId、FeatureId、模式/能力、前置状态、fixture/hash、操作序列、独立预期、实际结果、证据层次、源码/EXE 身份、日志/截图、状态、未覆盖原因`。安全记录仅用合成内容和非秘密 ID；不把真实正文、密码、TOTP seed 或密钥写入报告。
