# 查找浮层设计

日期：2026-10-18。分支 `feat/simplify-and-shell`。替换旧的“查找 / 替换”独立窗口（`FindReplaceDialog`），合并 main 之前完成。

## 目标

按用户友好的产品角度重做查找界面，保留现有全部搜索能力和边界：

- 正确的边界加无缝回退，不新增设置项。不同编码、类型、体积的文件上都能直接用。
- **当前文件的查找全部**是一等功能（来自 Notepad++）：结果进底部面板，双击跳到原文精确位置；千万行级日志后台搜索、可观测进度、可取消。
- 全部打开文件的查找全部在后台并行执行，进度可见。文件夹搜索不做，范围维持“当前文件 / 全部打开文件”。

## 交互

### 浮层（方向 A：右上角紧凑浮层）

- 每个窗口一个，悬浮在文档区右上角（标签栏下方），跟随文档区大小重新定位。目标始终是当前标签；切换标签保留查询和选项。
- **Ctrl+F**：打开浮层，查找框用编辑区选中文字（单行、非空）或光标处的词预填，否则保留上次查询；全选查找框。账号页上 Ctrl+F 仍聚焦账号搜索框（现状）。**Ctrl+R / Ctrl+H**（现有替换快捷键）：打开并展开替换行。
- **主行**：`›`（展开/收起替换行）、查找框（占位“查找”）、`Aa`（区分大小写）、`词`（整词）、`.*`（正则）、`01`（字节，仅当前文档是十六进制视图时出现）、`↑` `↓`、`⋯`、`✕`。
  - 开关互斥规则沿用现状：正则下整词禁用；字节下大小写、整词、正则全部关闭并禁用；剪贴板里的原始字节自动切到字节模式。
- **第二行**：左侧状态提示，右侧“**查找全部**”主按钮和范围下拉（“当前文件 / 全部打开文件 (N)”）。
- **替换行**（`›` 展开）：替换框（占位“替换为”）、“替换”“全部替换”。替换只作用于当前文件；全部打开文件范围、字节模式、只读大文件、二进制文档、锁定文档下替换行禁用，状态行说明原因（现有文案）。普通模式替换文本按字面写入，正则模式支持 `$1`、`${名称}` 等（现状）。
- **`⋯` 展开选项行**：循环查找（默认开）、正则助手（九个片段，行为同现状）。
- **按键**：Enter 下一个，Shift+Enter 上一个，Alt+Enter 查找全部，Esc 关闭浮层并把焦点还给编辑区。F3 / Shift+F3 浮层关闭时也可用（现状）。
- **忙碌**：查找全部进行中查找框、开关、范围禁用，“查找全部”变为“取消”（同一位置）；只读大文件忙碌期间仍可上一个/下一个（现状）。

### 边输入边查找（按文件分两档，无设置）

- **普通文件**（可编辑文本，即非窗口化只读大文件、非十六进制视图）：停止输入约 150 ms 后在后台跑一次查找全部（现有 `findAllL1Async`，上限 200,000 处），结果用于：正文高亮全部命中；选中打开浮层时光标处之后的第一处（不抢查找框焦点）；状态提示“第 3 / 128 处”，超过上限显示“第 3 / 200000+ 处”。上一个/下一个后更新序号。文档被编辑后，下一次导航前重算。
- **大文件、十六进制视图**：输入时不搜索。Enter 开始查找下一处，状态提示只说明找到与否，不显示总数；总数通过“查找全部”获得。
- 关闭浮层时清除由边输入产生的高亮。

### 提示（安静风格）

- 能运行但已降级：状态行一行灰字，带 ⓘ 悬停说明。例：非 UTF 编码大文件上的正则显示“按 GBK 子集匹配 ⓘ”。
- 不能运行：同样是状态行灰字，直接写原因和替代做法（现有错误文案），“查找全部”禁用。不加红框、不弹窗。
- 唯一的弹窗是“全部替换”完成/失败的结果（现状）。

### 底部结果面板

- 新的查找全部**替换**旧结果。面板标题行左侧有“↶ 最近搜索”按钮，列出最近 5 次查询（查询文字 + 范围）；选中一项把条件填回浮层并重新查找全部（只记条件、不缓存结果，内存不累积）。
- **当前文件**：现状不变——边搜边出、进度与取消、先字节偏移后补行号、超出内存预算写临时文件仍可滚动跳转、双击跳到精确位置、失效后“重新搜索”、技术详情。
- **全部打开文件**：
  - 开始时按**标签顺序**一次建好每个文件的分组，之后不移动。每组标题显示该文件状态：“等待”“搜索中 46%”（大文件）“N 处”“已跳过：已锁定”。
  - 摘要行显示“已完成 7/12 个文件 · 已找到至少 1,284 处”，完成后为现有完成/取消/不完整文案。
  - 各文件在共享线程池上并行执行（现状：普通文件的查找全部在后台调度器，大文件是异步任务，派发不等前一个完成）；不新建线程。
- 锁定会话时清除查询、结果和进行中的搜索，并关闭浮层（现状）。锁定文档和账号库不参与搜索（现状）。

## 边界（不变）

- 字节搜索只在当前文件且为十六进制视图。
- 全部打开文件范围只查找。
- 容量：可编辑文本 200,000 处；只读大文件内存保留 10,000–50,000 处，其余写临时文件。
- 正则语义与非 UTF 子集规则见 [正则语义](../../REGEX_SEMANTICS.md)。

## 实现要点

- `FindReplaceDialog`（QDialog）改为 `FindOverlay`（QFrame，文档标签控件的子控件），保留现有查询、导航、查找全部、替换和会话逻辑；只重写布局、按键、定位，并保留测试使用的控件 objectName 与类型（`findPatternEdit`、`findAllButton`、`regexSearchCheck` 等）。开关用 QCheckBox 加样式表现为切换按钮。
- 边输入边查找放在独立的 `FindLiveSearch`（QObject）：去抖、单任务在途、结果过期丢弃、序号计算。
- `DocumentSearchSurface` 新增两项：`searchCursor()`（选区字节范围与预填文字）和 `selectSearchHit(byteOffset, byteLength)`（选中但不移焦点）。
- `MultiSearchResultsModel` 增加预建分组与分组状态；`SearchResultsDock` 增加 `beginMultiFileResults(pattern, targets)`、`setMultiFileTargetState(...)` 与“最近搜索”按钮。
- 样式进应用样式表（`#findOverlay` 选择器），浅色、深色自动跟随；高对比度下沿用系统配色。
- MainWindow 方法数已到预算上限：只替换调用，不新增方法；EditorTab 方法预算按新增接口 +1 并在架构检查中注明。

## 评审后补充的规则

1. **边输入让位于查找全部。** 同一文档同时只有一个后台查找全部任务。边输入任务在途时又有输入，只记下最新查询，任务结束后再跑一次。显式查找全部（任一范围）开始前先取消边输入任务（`cancelFindAllL2` 对可编辑文本同样取消在途任务），不会出现“搜索任务未能启动”。浮层忙于显式查找全部时不跑边输入。
2. **高亮归属。** 显式查找全部的高亮覆盖边输入高亮；关闭浮层只清除仍归边输入所有的高亮。
3. **Enter 的起点。** 边输入选中光标处（或预填选区本身）之后的第一处；之后 Enter 从这处的末尾找下一处，即第二处（与 VS Code 一致）。
4. **体积上限。** 边输入只在文档 ≤ 4 MiB 时运行；更大的可编辑文本按大文件档处理（Enter 才搜索）。`DocumentSearchCursor` 带 `documentBytes`。
5. **序号上限。** 结果达到 200,000 处时显示“200000+ 处”；当前选区在已知结果内时显示“第 i / 200000+ 处”，否则只显示总数。
6. **无效正则。** 停止输入后在状态行显示错误原因（灰字），不跑边输入，不清除已有结果（现状）。
7. **范围。** 边输入始终只作用于当前标签；全部打开文件范围下上一个/下一个跨标签并按循环查找（现状）。
8. **全部打开文件。** 每个大文件的进度按目标单独转发到自己的分组（新增按目标的转发，不再只转发当前标签）；状态栏仍显示当前标签的进度。锁定文档显示为“已跳过：已锁定”分组，范围下拉中的数量仍只计可搜索文档。搜索中新打开的文档在末尾追加分组（与标签栏新标签位置一致）。各文件结果失效、“重新搜索”、跳过锁定的结束文案保持现状。
9. **最近搜索只在内存中**，最多 5 条，锁定会话时与查询一起清除，不写盘。
10. 切换标签取消当前文件范围的查找全部并重置（现状）。
