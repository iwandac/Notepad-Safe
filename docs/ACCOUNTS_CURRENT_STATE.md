# 账号库现状

更新：2026-10-16。按当前源码记录账号工作区的实际行为。会话、锁定与剪贴板总规则见 [加密与锁定现状](SECURITY_CURRENT_STATE.md)。来源：[`VaultDock.cpp`](../src/vault/VaultDock.cpp)（界面构建、账户文件、列表）、[`VaultDockEntries.cpp`](../src/vault/VaultDockEntries.cpp)（条目编辑、生成器、验证码、历史、健康检查、回收站、剪贴板）、[`VaultDockSupport.h`](../src/vault/VaultDockSupport.h)、[`MainWindow.cpp`](../src/window/MainWindow.cpp) 的 `showAccountsWorkspace`、[`KeePassXCVaultBackend.cpp`](../src/vault/KeePassXCVaultBackend.cpp)。

## 1. 入口与账户文件

- 入口：工具 › 账户（工具栏也有）。账号是与文档并列的**工作区**，不是一个标签；进入时隐藏搜索结果面板，状态栏显示“账户”。
- 首次进入要求安全会话（没有身份就先建立身份）。
- **默认账户文件**：`文档\Notepad Safe\accounts.kdbx`。存在则用会话的主密钥直接解锁；不存在则自动创建，并绑定身份的恢复能力。
- 默认文件用当前会话解不开（历史或外来文件）时，走统一打开流程的单次密码询问。
- 其他 KDBX 文件：通过文件 › 打开选择 `.kdbx`，可附带密钥文件；也有“新建账户文件…”“打开账户文件…”入口（目前在界面中隐藏，由统一打开流程承担）。
- 账户文件在磁盘上被别处修改时提示“账户文件已在磁盘上更改”，可放弃当前未保存的表单内容并重新打开磁盘版本，或取消后手动复制需要保留的字段。

## 2. 布局

- 顶部一行：搜索框（“搜索标题、用户名、网址、标签或备注”）、排序（标题 / 用户名 / 分组）、“健康检查”、“+ 新建账号”。
- 左侧列表（树形，两列“条目”“用户名 / 网址”）：
  - 根节点“账号”，下面按分组路径（`/` 或 `\` 分隔）逐级展开；
  - “旧版笔记（迁移）”（有内容才显示）；
  - “回收站”（有内容才显示，默认折叠）。
  - 第二列显示用户名，没有用户名时显示网址；已到期的条目显示为深红色“已到期 · …”，悬停提示到期时间。
- 右侧详情：标题、操作按钮（保存、取消、编辑、历史、克隆、恢复、移到回收站，按状态显示），下面是表单。
- 空状态：没有任何账号时整页显示“安全保存你的第一个账号”和“新建账号”；未选择条目时右侧显示“选择一个账号”。
- 账户文件未打开时显示“账户文件尚未打开。日常使用由当前安全会话自动解锁。”

## 3. 条目字段

| 字段 | 说明 |
|---|---|
| 标题 | 必填，保存时为空提示“标题不能为空。” |
| 用户名 | 旁边“复制”（30 秒后清除） |
| 网址 | 旁边“打开”：只接受 HTTP/HTTPS，用系统默认浏览器 |
| 标签 | 逗号分隔 |
| 分组 | 路径形式，例如“工作/生产环境” |
| 备用网址 | 每行一个 |
| 自定义字段 | 每行 `name=value`，名称不能重复；默认加密保护，`public:name=value` 表示公开字段 |
| 到期 | “此账号会过期”勾选 + 日期时间（默认三个月后） |
| 密码 | 默认隐藏；“显示密码”勾选后 30 秒、编辑结束或应用失去焦点时自动隐藏；“生成”；“复制”（30 秒后清除） |
| 密码强度 | 很弱 / 较弱 / 强 / 很强，带约多少 bit |
| 验证码密钥 | 隐藏显示；“设置…”打开验证码配置 |
| 当前验证码 | 每秒刷新，显示 6–8 位数字与剩余秒数；“复制验证码”（30 秒后清除）；未保存的新密钥显示“保存后显示” |
| 备注 | 纯文本 |

## 4. 编辑与保存

- 查看态字段只读；点“编辑”进入编辑态，“保存”/“取消”。主菜单的保存（Ctrl+S）在账号页保存当前条目，状态栏显示“未保存”。
- 有未保存修改时切换条目、离开账号页或锁定，询问“当前条目有未保存的修改。”保存 / 不保存 / 取消（默认保存）。主动锁定时若无法处理会取消锁定；会话到期和系统锁屏时会丢弃以清除明文。
- 每次保存前由 KeePassXC 建立条目历史。

## 5. 密码生成器

“生成密码”对话框：长度 8–128（默认 24）、小写 / 大写 / 数字 / 特殊字符、排除易混淆字符、每组选中的字符至少出现一次、额外排除字符。设置会记住。至少选一个字符集，否则提示。

## 6. 动态验证码

“设置动态验证码 (TOTP)”：密钥（Base32，或直接粘贴 `otpauth://` 链接，链接里的参数会自动填入）、算法 SHA1 / SHA256 / SHA512、位数 6–8、周期 5–300 秒（默认 30）。也可“移除验证码”。密钥为空或无效时提示。

## 7. 历史、克隆、回收站、健康检查

- **历史**：“账号历史 — 标题”，列出各版本的时间与变更摘要，列表不显示密码（只标注“此版本包含密码 / 没有密码”）。可恢复所选版本（当前版本自动保留进历史）、删除所选版本、清空历史（都需确认，删除和清空不可撤销）。
- **克隆**：复制账号及扩展字段，在同一分组生成副本“标题 - 副本”，并进入编辑。
- **回收站**：“移到回收站”需确认，之后可“恢复”；在回收站中再删即“永久删除”，需确认且不可撤销。回收站条目只读。即使导入的 KDBX 原本没有回收站，也保证可恢复的删除。
- **健康检查**：完全在本机检查空密码、弱密码、重复使用、已到期；无问题时弹提示，有问题时列出（不显示密码），可双击或“打开所选账号”跳转。有到期账号时顶部按钮变为“健康检查（N 到期）”。

## 8. 旧版笔记

以前版本存在账号库里的安全笔记显示在“旧版笔记（迁移）”下，只读，可移到回收站；新的加密笔记都是独立的 `.nsafe` 文档。

## 9. 锁定与离开

- 锁定（主动、到期、系统锁屏）时清空详情和剪贴板，回到“账户文件尚未打开”页；系统锁屏恢复后自动回到账号页。
- 离开账号页（到文档或安全中心）前先处理未保存修改并释放界面中的秘密。
- 账号不参与文档的“全部打开文件”搜索，也不进入会话恢复稿。

## 10. 新界面原型与现状的差异

| # | 差异 | 现状 | 处理 |
|---:|---|---|---|
| 1 | “常用”筛选 | **没有收藏/常用** | 原型新增，属于新功能；现状可用的是分组树、排序和搜索 |
| 2 | 列表形态 | 现状是分组树 + 两列 | 原型是扁平卡片列表；需要保留分组层级与“旧版笔记”“回收站”节点 |
| 3 | 排序选项 | 标题 / 用户名 / 分组 | 原型未画，需补 |
| 4 | 健康检查入口 | 顶部按钮 + 到期提示 | 原型放在设置页，需同时保留账号页入口 |
| 5 | 查看态与编辑态 | 现状有明确的“编辑”切换 | 原型一致；编辑表单的“自定义字段”现状是多行文本 `name=value`，原型画成逐行字段，属于交互改进 |
| 6 | 到期字段 | 日期时间，默认三个月后 | 原型只有日期，需补时间 |
| 7 | 验证码算法 | SHA1 / SHA256 / SHA512 | 原型写“SHA-1、位数 6、周期 30 秒”可点“更改”，一致 |
| 8 | 显示密码自动隐藏 | 30 秒或失去焦点自动隐藏 | 原型未体现，需补 |
| 9 | 命令面板直接复制密码 | 现状没有 | 原型新增，属于新功能（需遵守 30 秒清除） |
| 10 | 账户文件切换 | 默认文件 + 打开外部 KDBX | 原型标题栏只写“个人.kdbx”，默认文件名其实是 `accounts.kdbx` |
