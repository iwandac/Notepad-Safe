# 功能取舍

更新：2026-10-16。依据 [产品目标](PRODUCT_GOALS.md) 和 [架构评估](ARCHITECTURE_ASSESSMENT.md)，按四条标准逐项判断：**是否服务三块核心能力**（Notepad++ 级编辑搜索、方便的账号、加密文档）、**日常是否常用**、**实现与维护成本**、**数据或安全风险**。凡是增加第二条代码路径、模式判断或跨文档事务的，从严。

**状态：2026-10-17 已确认。**产品目标、核心旅程与各现状文档已同步标注；代码尚未修改，删除与新增按 [架构评估](ARCHITECTURE_ASSESSMENT.md) 的迁移步骤执行，完成一项后再把对应现状文档改为新行为。

## 1. 原型里提出的新功能

| 功能 | 决定 | 理由 |
|---|---|---|
| Ctrl+K 命令面板（命令、已打开文档、最近文件、账号） | **做** | 新外壳的统一入口，建在现有 `CommandRegistry` 上；替代大部分菜单查找 |
| 设置页 | **做** | 取代散在菜单里的勾选项，是新外壳必需的框架 |
| 设置页的“搜索设置”框 | 不做 | 设置项少于 20 个，分区就够 |
| 字体选择 | 不做 | 固定一种等宽字体足够，减少测试组合 |
| 字号设置 | **做，改为保存缩放** | 不新增设置项；把现有 Ctrl+滚轮缩放持久化并作用于所有编辑区，同时修掉“缩放不保存”的问题 |
| 显示行号开关 | 不做 | 始终显示，少一个分支 |
| Ctrl+F 用选中文字预填查找框 | **做** | 常用习惯，改动一处 |
| 转到行（Ctrl+G） | **做，仅可编辑文本** | Notepad++ 级编辑的基本功能，QScintilla 原生；只读大文件需要行索引，不做 |
| 查找命中计数“第 2 / 共 4” | 暂缓 | 需要每次导航都持有完整结果，大文件代价高；先保持现状 |
| 边输入边高亮 | 不做 | 大文件上要异步，与现有“查找全部后高亮”形成第二条路径 |
| 锁定后在标签内直接解锁 | **做** | 补现状缺口，复用现有登录流程，无新规则 |
| 登录框里改用恢复密钥 | 不做 | 恢复密钥已有入口（打开受保护文件、安全中心），极少用 |
| 闲置 N 分钟自动锁定 | 暂缓 | 现有 7 天会话 + 系统锁屏已覆盖；加计时会牵动所有编辑路径 |
| 启动恢复横幅 | 不做，改为提示条组件 | 新外壳只做一个非阻断提示组件（toast），恢复、保存成功、复制都用它 |
| 保存失败提示条（替代模态框） | **做** | 与上一条同一个组件；修改保留、可重试、不打断输入 |
| 关闭窗口时一次列出全部未保存文件 | 不做 | 现有逐个询问规则（未命名不问、加密自动写回）已稳定，合并列表要重新验证关闭流程 |
| 换行符各类数量与“混合”提示 | 不做 | 低频，需要全文统计 |
| 语言弹出层“常用”分组与筛选 | 不做 | 23 项一屏放得下 |
| 命令面板里直接复制账号密码 | **做** | 账号“取用要快”的核心体验；走现有复制路径和 30 秒清除，面板不显示秘密 |
| 账号表单逐行编辑自定义字段 | 不做 | 保持现有多行 `name=value`，少一套表单逻辑 |
| 账号表单“有未保存的修改”提示 | **做** | 只显示现有 dirty 状态 |
| 收藏 / 常用账号 | 不做 | 搜索 + 分组 + 命令面板已够；收藏要写入 KDBX 额外字段 |
| 书签持久化 | 不做 | 低频，需要扩展会话格式 |
| 编辑期间监视外部修改 | 不做 | 保存时检查已足够，监视器会引入后台状态 |

## 2. 现有功能

### 删除

| 功能 | 理由 | 影响 |
|---|---|---|
| **分屏**（左右/上下） | 第二个编辑器共享文档，是排序、书签、缩放出错的直接原因；日常少用；会话里还要存方向 | `canSplitView`、`m_splitEditor`、会话字段 `splitView`/`splitOrientation`、两个菜单项；旧会话里的分屏字段读取时忽略 |
| **文本/十六进制的实时切换**（视图 › 呈现方式、Ctrl+Shift+H） | 一个标签里切换表示是 `EditorTab` 双表示逻辑的主要来源；改为“内容决定视图” | 文本文件只用文本视图，二进制只用十六进制视图；保留标签右键“以十六进制重新打开 / 以文本重新打开”，作为**关闭再按另一种方式打开**，不再在同一视图内切换。二进制的文本呈现、字节偏移行号一并去掉 |
| **全部打开文件的全部替换** | 跨文件事务、预检、回滚，复杂且有改错文件的风险；很少用 | 保留“在全部打开文件中查找全部”；替换只作用于当前文件 |
| **全部打开文件范围的字节搜索** | 低频；字节搜索限当前文件即可 | 字节模式只在当前文件 |
| **加密二进制文档的新建与转换** | 加密文档的核心是文本笔记；加密二进制带来安全十六进制编辑这条额外路径 | 不再允许把二进制另存为安全文档；已有的加密二进制仍可打开、编辑、另存为普通文件，保证数据可取回 |
| 转置当前行、按窗口宽度拆分选中行 | 罕用，菜单噪音 | 两个菜单项 |
| 主工具栏 | 新外壳不再有工具栏 | 菜单项与设置 |

### 简化

| 功能 | 简化为 |
|---|---|
| 长行标尺 6 档列宽 | 开关 + 80 / 100 / 120 三档 |
| Tab 宽度 2/4/8 | 保留，不变 |
| 后台任务面板 | 状态栏任务指示 + 简单列表（名称、进度、取消、错误详情） |
| 账户文件管理 | 默认账户文件 + 打开外部 KDBX；不再提供“新建账户文件”入口（已隐藏） |
| 旧版笔记 | 保持只读迁移展示；不加新功能，后续版本在确认无人使用后删除 |

### 保留不变

文本编辑核心（撤销、剪贴板、行复制/删除/移动/排序、大小写、合并行、多选、括号、书签、折叠、补全、23 种语言）、查找替换（普通/正则/字节、正则助手、查找全部与结果面板）、编码识别与重新显示、转换编码另存、换行转换、只读大文件与日志跟随、可编辑十六进制（含插入模式）、保存与恢复全部规则、加密文档、安全中心、账号库现有字段与历史/回收站/健康检查/克隆、单实例、最近打开。

## 3. 对目标和旅程的影响（已同步）

- [产品目标](PRODUCT_GOALS.md) 的稳定目标去掉“分屏”，加上“转到行”。
- 核心旅程 J3 去掉“分屏中操作”；J4 的全部替换限当前文件。
- 架构上：没有分屏和实时切换后，三个视图（文本、十六进制、只读）各自独立，`EditorTab` 不再需要双表示状态，第 3 步迁移的范围明显变小。
