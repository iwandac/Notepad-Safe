# 搜索功能现状

更新：2026-10-17。本页按当前源码逐项记录搜索、替换与结果面板的实际行为，作为新界面和架构评估的依据。它描述“现在是什么”，不是验收结论；测试是否通过见 [执行账本](DAILY_USE_CLOSEOUT.md)。主要来源：[`FindOverlay.cpp`](../src/search/FindOverlay.cpp)、[`MainWindowCommands.cpp`](../src/window/MainWindowCommands.cpp)、[`EditorTabSearch.cpp`](../src/editor/EditorTabSearch.cpp)、[`Pcre2Regex.cpp`](../src/search/Pcre2Regex.cpp)、[`SearchResultsDock.cpp`](../src/search/SearchResultsDock.cpp)、[`SearchResultsModel.cpp`](../src/search/SearchResultsModel.cpp)、[`DynamicThresholds.cpp`](../src/editor/DynamicThresholds.cpp)，语义合同见 [正则语义](REGEX_SEMANTICS.md) 与 [搜索契约矩阵](../tests/gui_smoke/SEARCH_REPLACE_CONTRACT_MATRIX.md)。

## 1. 入口

| 操作 | 行为 |
|---|---|
| Ctrl+F / 菜单“查找” | 打开**非模态**查找窗口，标题为“查找”，隐藏替换控件；焦点进查找框并全选已有内容。**不会**用编辑区选区预填查找框。账号页激活时，Ctrl+F 改为聚焦账号搜索框，不打开查找窗口 |
| Ctrl+R / 菜单“替换” | 同一窗口切到“替换”标题并显示替换控件；账号页激活时无效 |
| F3 / Shift+F3 | 用最后一次查找条件（内容、正则、大小写、整词）向后/向前查找，查找窗口关闭时也可用；没有查找过时无效 |
| 查找框按 Enter | 等同“查找下一个” |
| 关闭按钮 / Esc | 只隐藏窗口，条件保留 |

查找窗口跟随当前标签：切换标签时目标随之改变，当前文件范围内未完成的导航和查找全部会被作废。

## 2. 查询模式与选项

只有三种互斥模式，用复选框表达，GUI 直接禁用冲突项，而不是点了再互相取消：

| 模式 | 可用选项 | 被禁用并清除 | 适用目标 |
|---|---|---|---|
| 普通查找（默认） | 区分大小写、整词匹配、循环查找、范围 | 无 | 所有可搜索文本，含加密文本 |
| 正则表达式 | 区分大小写、循环查找、范围 | 整词匹配、十六进制字节 | 同上 |
| 十六进制字节 | 循环查找 | 正则、区分大小写、整词 | 只在“当前文件”范围、且当前文档处于十六进制视图时可用；切到“全部打开文件”时取消勾选并禁用 |

- **循环查找**默认开启。只影响下一个/上一个到达边界后是否回绕一次，不影响“查找全部”的结果集合。
- **整词**：西文按单词边界；中文、日文、韩文按完整短语精确匹配（工具提示有说明）。非 UTF 编码按 ASCII 词边界。
- **范围**下拉框：“当前文件”或“全部打开文件 (N)”，N 是当前可搜索的标签数（已锁定或正在切换的加密文档不计入）。没有目录搜索。
- **查询为空**：下一个、上一个、查找全部、替换、全部替换全部禁用。
- **剪贴板原始字节识别**：从十六进制字符栏复制的内容粘贴进查找框时，若字节模式可用，会自动勾选“十六进制字节”并提示“已识别字符栏中的原始字节，按精确字节搜索。”
- **字节格式**：`DE AD BE EF`、连续 `DEADBEEF`、逗号、连字符、`0x` 前缀、大小写均可；奇数位、非十六进制字符原子拒绝。字节模式下占位符为“例如 DE AD BE EF”。

## 3. 正则

- 引擎只有 PCRE2 10.47。小文件、加密文本、UTF-8 大文件用 UTF + UCP 模式，支持 Unicode 属性、完整字符类、前后断言、反向引用、命名捕获；二进制的文本投影含非法 UTF-8 时仍可匹配。
- 非 UTF 编码的只读大文件（UTF-16LE/BE、GBK、GB18030、Big5、Shift-JIS、Windows-1252）不全文转码，只支持登记的日志子集（`.` `^` `$` `|`、量词、捕获/命名捕获、反向引用、前瞻、定长 ASCII 后顾、ASCII 语义的 `\d \s \w \b`、`\R`、开头的 `(?i)(?m)(?s)`）。`\p{…}`、非 ASCII 范围、变长后顾、递归等在扫描前以短错误拒绝。
- **实时校验**：勾选正则且查询非空时，窗口内提示行显示绿色“正则有效”，或红色简短错误（悬停显示完整错误）。非 UTF 大文件用子集编译器校验，所以子集外的写法也在这里报错。非正则时提示行显示“普通查找”或“原始字节搜索”。
- **无效正则**：“查找全部”不清空旧结果、不启动后台扫描，只在状态行显示错误。
- **正则助手**：按钮可开关；开启时若未勾选正则会自动勾选，字节模式和忙碌时禁用。九个片段：原样文本（把查找框中的选中文字转义为字面量）、任意内容 `.*?`、数字 `\d+`、单词 `\w+`、空白 `\s+`、捕获 `(?<字段>…)`、任选 `(?:A|B)`、行首 `^`、行尾 `$`。有选中文字时包裹选中内容；没有时插入占位文字并把占位文字选中，便于直接改写。
- **零长度匹配**（`^`、`$`、前后断言、空分支）：查找可终止并按一个字符前进；全部替换明确拒绝。
- 匹配为非重叠全局语义（`banana` 中找 `ana` 只命中一次）。

## 4. 查找下一个 / 上一个

- 严格前进或后退；当前选区已是本条件的命中时，跳过它找下一处，不重复。
- 每次导航是一个请求，进行中时下一个/上一个按钮禁用，状态行显示“查找下一个…”或“查找上一个…”。
- 可编辑文本：正文在内联预算内、或刚做过同条件的查找全部（缓存与文档版本一致）时，直接用 PCRE2 在 QScintilla 的 UTF-8 正文上查找；否则取快照在后台扫描，结果回来时文档版本仍一致才选中。
- 只读大文件：后台异步，第一处命中到达即选中，不等全量结果。
- 全部打开文件范围：从当前标签开始按标签顺序前进（上一个则反向），跳过锁定文档，激活命中所在标签、选中精确范围、焦点回到编辑区。开启循环时，走完末尾后从第一个标签绕回，最后再回到起始标签。
- 结果反馈只在状态行：“未找到更多匹配”、“未找到匹配。”、“已到范围边界。”、错误、“当前安全文档已锁定。”、“字节搜索仅适用于十六进制视图。”
- **没有“第几处/共几处”计数**，也没有边输入边高亮。

## 5. 查找全部与正文高亮

- 先整体校验查询，再清空旧结果并开始。
- **当前文件、小文件**：快照在 UI 线程取，编译、扫描和结果整理在后台调度器执行；窗口显示“正在搜索…”。完成后在正文以指示器高亮全部命中，并把结果放入搜索结果面板。
- **当前文件、只读大文件**：异步任务，带进度（“搜索中 N% · 已扫描 / 总量”，同时显示在主窗口状态栏），边扫描边向面板追加预览；结果先有字节偏移，行号统计完成后再补上。有效 UTF-8 正则先校验全文（进度前 20%），再匹配（后 80%）。
- **全部打开文件**（只做文本查找）：每个事件循环只派发一个文档，过程中可取消；锁定文档会被跳过并计数；搜索进行中新打开的文件会被加入（或按同样规则跳过）。结束时有跳过项则状态行显示“搜索完成：跳过锁定文档 N 个。”
- **忙碌状态**：查找框、模式、范围、全部替换和重复启动都禁用，显示“取消搜索”按钮；取消后保留已完成结果，提示“搜索已取消，已保留完成的结果。”只读大文件忙碌期间仍可查找下一个/上一个。
- **容量**：可编辑文本最多 200,000 处，超出即标为不完整；只读大文件在内存中保留 10,000–50,000 处（按内存计算），其余写入临时文件，面板可滚动到末尾仍能跳转。可编辑文本中单个匹配超过 2 GiB 报错。

## 6. 搜索结果面板

- 停靠面板“搜索结果”，查找全部完成时自动显示。
- **一行对应正文一行**（字节模式为一个偏移片段），列为“行”或“偏移”、“内容”、“匹配数”；同一行的多处命中在内容里内联高亮，并在“匹配数”列计数。悬停提示“第 N 行 · N 处匹配 / 内容 / 双击跳转”。多文件时按文件分组。
- **双击**激活所属标签并选中精确范围，不改变文档的修改状态。
- **摘要行**按状态变化：“文件 · “查询” · N 处”；进行中“正在搜索 “查询”…”“已发现至少 N 处…”；不完整“至少 N 处（原因）”；全部打开文件时“在全部打开文件中搜索 “查询”：找到 N 处匹配”，以及不完整、已失效、已取消的对应文案。
- **失效**：文档被编辑后该文件结果失效，显示“文档内容已修改，原有 N 处搜索结果已失效；请重新搜索。”并出现“重新搜索”按钮（用当前条件重跑，优先激活原文档）；源文档关闭后显示“源文档已关闭…”；只影响相关文件，其他文件结果仍可跳。
- **技术详情**按钮展开原始诊断，不重新搜索。
- 每个结果模型按自己搜索时的编码和快照解码；改变显示编码或调整面板宽度不会改写已有结果。

## 7. 替换

- **替换只作用于当前文件**。范围为“全部打开文件”时替换、全部替换和替换框都禁用，替换模式下状态行显示“全部打开文件范围只查找；替换只作用于当前文件。”
- **单次替换**：当前选区是本条件的命中就替换它，否则先找到下一处再替换；替换后自动选中下一处。
- **只能替换可编辑文本**：只读大文件、二进制文档、锁定或切换中的加密文档，替换入口全部禁用；字节模式只查找，状态行提示“字节模式仅查找；编辑请回到十六进制视图。”
- **替换文本语法**：普通模式按字面写入，`$1`、`\1`、`\n` 都不展开；正则模式支持 `$1`、`${名称}`、`\1`、`$$`（字面 `$`）、`\n` `\r` `\t` `\\`。引用不存在的捕获组、`${` 未闭合、空引用都是错误；未参与匹配的可选组展开为空。空替换文本是合法的删除。
- **当前文件全部替换**：成功后弹窗“已替换 N 处匹配。”；一次撤销还原；不自动保存。命中超过 200,000 处或含零长度匹配时拒绝，提示“查找结果未完整生成，未进行任何替换…”。

## 8. 与锁定和隐私的关系

- 锁定加密会话时清除：查找框和替换框内容、最后一次查找条件、搜索结果面板、正在进行的搜索；查找窗口被隐藏。
- 锁定或切换中的加密文档不参与任何查找和替换，在全部打开文件的摘要中计入“锁定”。
- 账号库不是可搜索文档，不参与全部打开文件搜索；它有自己的搜索框（标题、用户名、网址、标签、备注）。

## 9. 新界面原型与现状的差异

原型画的是方向，下列各项必须按现状补齐，或作为新功能单独决定：

| # | 差异 | 现状 | 处理 |
|---:|---|---|---|
| 1 | 模式表达 | 三种互斥模式，冲突项禁用 | 浮层改为“普通 / 正则 / 字节”三段切换；整词在正则下禁用；大小写在字节模式下禁用 |
| 2 | 十六进制字节模式 | 有，含剪贴板识别 | 原型缺失，需补 |
| 3 | 循环查找 | 有，默认开 | 原型缺失，需补 |
| 4 | 范围计数 | “全部打开文件 (N)” | 补计数；全部打开范围下替换行禁用并说明 |
| 5 | 命中计数“2 / 4” | **没有** | 原型新增，属于新功能，需决定是否做 |
| 6 | 边输入边高亮 | **没有**，高亮只在查找全部后出现 | 原型新增，属于新功能；大文件上需要异步，需决定 |
| 7 | 状态行 | 有，承载错误、未找到、跳过摘要、进度 | 浮层需要一条状态行 |
| 8 | 忙碌与取消 | 查找全部进行中禁用输入，显示取消 | 原型缺失，需补 |
| 9 | 正则校验 | 绿色有效 / 红色简短错误 + 悬停全文；非 UTF 大文件用子集校验 | 原型已有简化版；需支持子集错误文案 |
| 10 | 正则助手 | 九个片段，包裹选中文字或插入并选中占位 | 原型片段一致；插入行为需按现状 |
| 11 | 替换语法说明 | 普通模式不展开 `$1` | 原型只在正则下说明，需注明普通模式按字面写入 |
| 12 | 只读与二进制 | 替换入口禁用并有提示 | 原型在只读日志上仍显示可用替换行，需改为禁用并说明 |
| 13 | 结果面板 | 每行带“匹配数”列、行号或偏移、失效与“重新搜索”、技术详情、进度、取消 | 原型只有分组与内容，需补 |
| 14 | 全部打开文件的全部替换 | 已删除 | 不需要对应画面 |
| 15 | 锁定时清除搜索状态 | 清空查询、结果并隐藏查找窗口 | 原型锁定后查找浮层和查询仍在，需改 |
| 16 | Ctrl+F 选区预填 | **没有** | 原型未涉及；预填是常见习惯，属于新功能，需决定 |
| 17 | 账号页的 Ctrl+F | 聚焦账号搜索 | 原型未体现，需补 |
| 18 | 浮层的归属 | 现为一个跟随当前标签的独立窗口 | 浮层应为每个窗口一个，切换标签时保留条件、目标跟随当前标签 |

2026-10-17 按 [功能取舍](FEATURE_DECISIONS.md) 确认。全部打开文件范围只查找、字节搜索只在当前文件已实现并写入正文；以下尚未实现。

- 新增 Ctrl+F 用编辑区选中文字预填查找框。
- 暂缓命中计数；不做边输入边高亮。第 9 节差异表中 #5、#6 按此处理，#16 改为“做”。
