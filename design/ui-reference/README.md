# Notepad Safe：HTML 交互设计参考

直接用浏览器打开 `index.html`。页面没有外部依赖，无需安装、构建或联网。

## 设计方向

采用正文优先的紧凑布局：36 px 顶栏合并菜单、标签、新建、查找和安全入口，20 px 底栏显示保存与光标状态。取消常驻侧栏、大标题和独立工具栏。默认隐藏行号，可在更多菜单开启。查找替换使用按需浮层，文件操作与账号入口放在左上菜单，外观等操作放在右上更多菜单。保留暖白与深石墨外观。编辑文档与只读文档共用标签、查找、排版和状态栏；只读场景保留阅读操作，并明确禁用写入操作。安全文档和账号页共享锁定状态。

## 可以体验的流程

- 编辑工作笔记 → 未保存标记 → Ctrl+S 保存本次演示 → 关闭 → 从“打开”重开；保存内容在本次页面会话中保留。
- Ctrl+F 查找 → 中文匹配、大小写开关、前后导航 → 展开替换 → 单处或全部替换。
- 切换部署日志 → 查找、选择、复制、调整字号和换行；正文只读，不能替换。
- 打开私人备忘 → 锁定安全会话 → 输入错误口令观察反馈 → 使用演示口令 `demo` 解锁。
- 切换账号保险箱 → 搜索虚构账号、查看详情、显示/隐藏演示密码。
- 右上更多菜单 → 演示保存失败 → 修改仍保留 → 重试保存。
- Ctrl+K 搜索文档或命令；新建文档；关闭未保存文档时选择继续编辑、放弃或保存。
- 右上更多菜单调整主题、字号、自动换行与行号；左上主菜单打开账号保险箱，账号页可以返回文档，也可直接点击文档标签。

## 原型边界

这是视觉与交互参考，不是 Qt 客户端，也不是产品回归测试的替代品。未实现 KDBX 加密、安全内存、大文件引擎或磁盘保存。锁定只隐藏界面内容；所有演示内容仍存在页面内存中。日志的 64.8 MB 是场景标签，正文只是合成片段。

“保存”仅更新本次页面会话的内容，刷新即重置，不产生备份或持久化副本。本机导入仅供体验，限 1 MB 内 UTF-8 文本，行尾统一为 LF；不修改源文件。不要输入真实秘密或口令。
